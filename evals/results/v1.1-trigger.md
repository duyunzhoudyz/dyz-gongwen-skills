# gongwen-skills v1.1 触发评测重跑

评测日期：2026-11-04
冻结提交：`3845d23`
对照：v1.0 触发评测（`v1.0-benchmark.md` 第六节，提交 `a1e067c`）

## 一、目的

gongwen-brief、gongwen-format、gongwen-humanize 三个 skill 的 `description` 在 v1.0 评测提交 `a1e067c` 之后有改动，所以重跑触发评测。其余 19 个 skill 的 `description` 没有变化，已逐个比对 frontmatter 确认。

## 二、方法

- 22 个 skill 全部作为候选池，题库为全部 440 条说法，与 v1.0 相同，分 8 批，每批 55 条。
- 答题方为 Sonnet 5.5 子智能体，使用默认推理强度。v1.0 没有记录推理强度，两次是否可比无法确认。
- 每条说法只作答一次，没有重复运行，看不出随机波动。
- 评测目录在仓库外，冻结的提交为 `3845d23`。

## 三、结果

| 口径 | v1.0 | v1.1 |
|---|---|---|
| 全部说法 | 439/440 | **440/440** |
| 正例（应触发本 skill） | 219/220 | 220/220 |
| 反例（不应触发本 skill） | 220/220 | 220/220 |

- 22 个 skill 的正例、反例都是 10/10。
- v1.0 唯一判错的 gongwen-title#8（“请示标题写成‘关于申请购置设备的请示报告’行不行”，v1.0 判给了 gongwen-draft），这次判对。

## 四、brief、format、humanize 专项

- 三个 skill 的正例全部判回自己，反例没有一条判给自己。
- 别的 skill 的说法被判给这三个 skill 的共 36 条（format 13、humanize 13、brief 10），全部是别的 skill 的反例，没有抢走任何正例。这 36 条与 v1.0 逐条相同，说明新 `description` 没有改变归属。
- 边界较模糊、可再复核的 4 条：
  - gongwen-review#14：核稿意见写成 Word 批注，判给 gongwen-format；
  - gongwen-profile#16：按画像写版头，判给 gongwen-format；
  - gongwen-review#18：判断信息能否被采用，判给 gongwen-brief；
  - gongwen-direct#13：替换“赋能、闭环、打造”，判给 gongwen-humanize。

## 五、结论

22 个 skill 全部达到 `CONTRIBUTING.md` 的 Stable 触发标准（正例 ≥9/10，反例 10/10）。brief、format、humanize 的触发结果不再过期。

局限：触发评测是模拟（只给描述、只在 22 个 skill 里选，没有其他无关 skill 的干扰）；每条说法只答一次；v1.0 与本次的推理强度可能不同。
