# 单位信息中心入网评估与部署指引

> 适用对象：党政机关、事业单位、国有企业办公室、信息中心（网信办）、保密工作部门。
> 配套材料：离线包根目录《安全自查报告.md》《SHA256SUMS.txt》《离线使用说明.md》。

---

## 一、项目定性与安全边界（为什么不是“龙虾类”自主智能体）

近期部分单位明确禁止引入“龙虾类”（OpenClaw 等）高权限自主智能体工具，主要风险在于其具备后台常驻进程、自主调用系统命令行、全盘文件读写和主动连接外部接口的能力。

本交付包（`dyz-gongwen-skills` 信创离线版）在架构上**完全剥离了 Agent 自主执行机制**，二者对比如下：

| 维度 | 龙虾类自主智能体（被禁类别） | 本项目信创离线版 |
|---|---|---|
| 运行形态 | 后台常驻守护进程 / 自主循环规划 | **无后台进程、无 Agent 循环**；全部功能由人员手动点击或单次命令触发 |
| 系统与文件权限 | 自主执行 Shell、读写任意目录 | 脚本仅处理使用者显式粘贴的文本或手动选择的文件；不扫描业务目录 |
| 网络外联 | 主动调用公网大模型与第三方工具 | **全量零外联**（静态 AST 审计禁用全部联网库）；本机工具箱强制绑定 `127.0.0.1` |
| 源码透明度 | 常含闭源插件或远端动态加载 | 全部 Python 脚本与 WPS JS 宏均为明文 UTF-8 源码，禁用 `eval`/`exec`，附 `SHA256SUMS.txt` |
| 知识库与模型集成 | 依赖外部 Agent 调度 | 静态提示词（`dist/prompts-lite/`、`dist/prompts-bundles/`）与知识切片（`dist/rag-kb/`），Dify 模板已显式关闭 `agent_mode: false` |
| 字库合规 | 可能混带未授权字库 | **不打包任何 `.ttf`/`.otf`/`.ttc` 商用字体文件**，无字体版权与未知二进制风险 |

## 二、三类网络环境分级使用边界

本工具仅为文字辅助、本地脱敏与格式校验工具，**不提供也不替代任何涉密信息系统测评资质**。请按所在网络密级严格区分使用方式：

| 网络环境 | 允许使用的组件 | 硬红线与注意事项 |
|---|---|---|
| **涉密信息系统（涉密内网）** | **不建议直接引入**；确需离线辅助排版的，须先履行本单位保密审批与入网安全检测，仅限使用无联网能力的静态规范与空白 `.docx` 模板 | 严禁通过非涉密 U 盘拷入；严禁将涉密载体材料带出或输入非涉密内网模型 |
| **非涉密政务内网 / 单位局域网**（已部署内网大模型或 Dify/MaxKB） | 全套可用：`dist/rag-kb/` 知识库 + `dist/prompts-bundles/` 提示词 + `xinchuang/` 本机工具箱 + 空白模板 | 1. 严禁输入标注绝密/机密/秘密、工作秘密、内部资料的材料（工具箱内置强拦截，命中即拒）；<br>2. 含个人隐私（身份证、手机、姓名等）的常规非涉密材料，先在本机工具箱脱敏再送内网模型，改完后在本机还原；<br>3. 脱敏**不能**让涉密材料合规进入非涉密网络 |
| **纯单机离线办公机**（不连任何网络、无大模型） | `xinchuang/` 本机工具箱（涉密扫描、八关机检、事实数字核对、字体自检、国标排版、OFD 体检）、`xinchuang/templates/` 空白模板、`wps_gongwen_macro.js` | 全程在本机运行，零外联，不依赖任何大模型 |

## 三、信息中心三种推荐落地模式

单位可根据自身运维条件，从轻到重任选一种：

### 模式 A：科室轻量试点（零服务端部署，10 分钟落地）
1. 信息中心审核离线包 `dyz-gongwen-skills-offline-<版本>.zip` 后，上传至单位内网共享盘。
2. 干部下载解压到本机，双击 `xinchuang/启动工具箱.sh`（银河麒麟 / 统信 UOS）或 `xinchuang/启动工具箱.bat`（Windows）即可在浏览器使用全部本地核稿、脱敏、排版与 OFD 体检功能。
3. 未装 Python 且禁用了 WPS 宏的电脑，直接打开 `xinchuang/templates/` 下的 5 套 GB/T 9704 空白 `.docx` 模板粘贴正文即可。

### 模式 B：单位统一内网知识库入口（推荐全局推广）
1. 信息中心在单位已有的 **Dify / MaxKB / FastGPT / 扣子开源版** 中新建「政务公文知识库」，按 `dist/rag-kb/README.md` 导入 `dist/rag-kb/chunks/` 或对应 QA CSV。当前构建含 16 个切片文件、462 个带条款锚点的标准知识片，数量以工具生成的 `dist/rag-kb/README.md` 为准。
2. Dify 可直接导入 `dist/rag-kb/dify-app-template.yml`（已默认关闭 Agent 模式、固定低温度 `0.2`），关联本单位内网大模型（如 DeepSeek-R1/V3、Qwen 32B/72B 等）后发布统一内网网址。
3. 全单位干部直接通过内网浏览器访问，个人电脑无需安装任何软件，规则版本由信息中心统一升级维护。

### 模式 C：内网离线依赖分发（完整七种国标版式）
- 本机工具箱的涉密扫描、脱敏还原、八关机检、事实核对、OFD 体检和**轻量国标排版**（`xinchuang/lite_docx.py`）全部只依赖 Python 标准库，无需 `pip`。
- 如需支持红头套打、联合行文、Markdown 表格、完整版记表格等七种完整版式，才需要 `python-docx`、`openpyxl`、`lxml`：
  - **x86_64 / 飞腾・鲲鹏 ARM64（aarch64）/ Windows**：信息中心在隔离外网机运行 `python tools/build_wheelhouse.py --arch all`，将生成的 `wheelhouse/` 审核后随离线包分发，终端按对应目录 `INSTALL.txt` 离线安装。
  - **龙芯（loongarch64）**：从 Loongnix / 统信 UOS / openEuler 单位内网软件源安装系统包 `python3-lxml python3-openpyxl python3-docx`；暂无法安装时，工具箱自动切换零依赖轻量排版，不影响正常出稿。

## 四、信息中心 5 分钟入网复核清单

以下 5 步可直接作为单位软件入网审核记录：

1. **文件完整性校验**
   ```bash
   cd <离线包解压目录>
   sha256sum -c SHA256SUMS.txt
   ```
   预期：全部文件输出 `OK`（或 `确定`），0 项失败。

2. **静态零外联与无动态执行复核**
   - 查阅根目录《安全自查报告.md》，确认结论为「通过（0 项违规）」。
   - 有源码仓库时可独立复跑：
     ```bash
     python3 tools/security_audit.py --strict
     ```
   - 核查白名单项仅限 4 处（均在报告第二节逐行列出）：
     - `skills/gongwen-format/scripts/gw_fonts.py`：`subprocess` 仅调用 `fc-list` 读字体名；
     - `skills/gongwen-format/scripts/preview_docx.py`：`subprocess` 仅调用本机 LibreOffice 预览；
     - `tools/install.py`：`subprocess` 仅在用户执行安装器时运行本包 `gw_fonts.py`；
     - `xinchuang/local_toolbox.py`：`http.server` 硬编码绑定 `127.0.0.1` 并校验 `Host`/`Origin`。

3. **实机监听端口与零外联验证**
   - 启动 `python3 xinchuang/local_toolbox.py` 后，在另一终端执行：
     ```bash
     ss -lntp | grep 8765
     ```
   - 预期：监听地址为 `127.0.0.1:8765`（而非 `0.0.0.0` 或局域网 IP），局域网其他主机无法访问；断网状态下全部按钮正常运行。

4. **涉密标识强拦截冒烟**
   - 在工具箱左框输入“机密★5年 测试文本”或“内部资料，不得外传”，点击「② 脱敏（左框）」。
   - 预期：立即返回 `[强拦截]` 拒绝脱敏，映射表为空。

5. **商用字体与二进制核查**
   ```bash
   find . -type f \( -iname '*.ttf' -o -iname '*.otf' -o -iname '*.ttc' -o -iname '*.exe' -o -iname '*.dll' -o -iname '*.so' \)
   ```
   预期：除信息中心主动附加的 `wheelhouse/` 外，输出为空（0 个字体文件、0 个未知可执行二进制）。
