### T03　离线安装 Python 排版依赖（无外网、无 pip 源、非管理员，可选）

- **前置条件**：测试机不联网、未配置内部 PyPI 源、使用普通非管理员账户；离线包内带有 `wheelhouse/` 目录（若离线包不含 `wheelhouse/` 或本单位决定只用零依赖轻量排版与空白模板，本项选“不适用”并在备注说明）。
- **操作步骤**：
  1. 查看架构与 Python 次版本：
     ```bash
     ARCH="$(uname -m)"
     PYVER="$(python3 -c 'import sys; print(f"{sys.version_info[0]}.{sys.version_info[1]}")')"
     echo "ARCH=$ARCH  PYVER=$PYVER"
     ls -la wheelhouse/
     ```
  2. **飞腾/鲲鹏（`aarch64`）或兆芯/海光（`x86_64`）**：确认 `wheelhouse/${ARCH}/py${PYVER}/` 存在后校验并用户级离线安装：
     ```bash
     (cd "wheelhouse/${ARCH}/py${PYVER}" && sha256sum -c SHA256SUMS.txt)
     python3 -m pip install --user --no-index --find-links "wheelhouse/${ARCH}/py${PYVER}" python-docx openpyxl
     python3 -c "import docx, openpyxl, lxml; print('DEPS_OK')"
     ```
  3. **无 `pip` 时的兜底验证**（按对应目录 `INSTALL.txt` 第三节）：
     ```bash
     python3 -m ensurepip --user 2>&1 || true
     # 若仍无 pip，用纯标准库解压 wheel 到临时目录并用 PYTHONPATH 导入验证：
     python3 -c "import glob, zipfile; [zipfile.ZipFile(f).extractall('/tmp/gw-accept/gw_site') for f in glob.glob('wheelhouse/${ARCH}/py${PYVER}/*.whl')]"
     PYTHONPATH=/tmp/gw-accept/gw_site python3 -c "import docx, openpyxl, lxml; print('SITE_OK')"
     ```
  4. **龙芯（`loongarch64`）**：查阅 `cat wheelhouse/loongarch64/INSTALL.txt`，记录本单位内网软件源是否提供 `python3-lxml python3-openpyxl python3-docx`（无管理员权限或源内缺失时跳过安装，直接走后续零依赖轻量排版验收）。
- **预期结果**：
  1. `x86_64` / `aarch64` 在 Python 3.9～3.12 下离线安装不尝试联网，最终打印 `DEPS_OK`（或无 pip 兜底打印 `SITE_OK`）；
  2. 龙芯明确呈现 `wheelhouse/loongarch64/INSTALL.txt` 指引，不误尝试下载公网包。
- **不通过时先查什么**：
  1. 报错 `externally-managed-environment`（PEP 668）时，在 `pip install` 后追加 `--break-system-packages` 重试，或改用第 3 步 `PYTHONPATH` 方案；
  2. `import lxml` 报 `GLIBC_2.xx not found`，说明系统 glibc 低于 `manylinux2014`（2.17）或与 wheel ABI 不匹配，停止硬装并记录，改用零依赖轻量排版（T17）和空白模板（T19）；

### T30　仅监听本机回环地址与跨站请求拦截（Host / Origin 校验）

- **前置条件**：工具箱正在运行（假设监听 `127.0.0.1:8765`，若顺延请替换端口号）。
- **操作步骤**：
  ```bash
  # 1. 核查监听地址
  ss -lntp | grep 8765
  # 2. 验证伪造 Host 与伪造 Origin 均被拒绝（防 DNS 重绑定与外部网页调用）
  curl -sS -i -H "Host: evil.example:8765" http://127.0.0.1:8765/ | head -n 8
  curl -sS -i -X POST -H "Origin: http://evil.example" -H "Content-Type: application/json" -d '{"a":"test"}' http://127.0.0.1:8765/api/secret | head -n 8
  # 3. 本机局域网 IP 探测（仅在连入局域网时测）
  LAN_IP="$(hostname -I | awk '{print $1}')"
  [ -n "$LAN_IP" ] && curl -sS --connect-timeout 3 "http://${LAN_IP}:8765/" 2>&1 || echo "无局域网IP"
  ```
  > 如有同网段另一台测试机，从另一台机器浏览器访问 `http://<本机局域网IP>:8765/` 交叉确认。
