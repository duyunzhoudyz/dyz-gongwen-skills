> 核验日期：2026-11-04

只收本包文书常用、容易写错的术语。解释用于理解和核对用法，写进正文的政治性表述仍以用户提供的原文为准。“出处”列写到文件名称、文号和年份，能核实到条号的写条号；只能从学校转发件核实的注明“据某校转发”；本表没有的制度和条号，正文只写名称，条号列入起草说明待核实，不凭记忆写。本轮条号已对照中国政府网、教育部网站的原文或转载件逐条核对，只见转载件的注明“据某某转载”。简版画像中已有的术语（党委领导下的校长负责制、立德树人、三全育人、双一流、高基报表、教代会、课程思政、意识形态工作责任制、校院两级管理）见 `references/_shared/profiles/units/gaoxiao.md` 第五部分，本表只补充其中易写错的口径。

|---|---|---|
| 审核评估 | 普通本科高校本科教育教学审核评估，每5年一个周期 | 教督〔2021〕1号（2021—2025年） |
| 两类四种 | 第一类面向以建设世界一流大学为目标的高校；第二类分三种：学术型、应用型、首次参评的地方应用型高校 | 同上 |
| 合格评估 | 面向新建本科院校的本科教学工作评估；原则上获“通过”结论5年后参加审核评估 | 同上 |
| 自评报告 | 学校自评阶段形成并公示的报告，是专家线上评估的主要材料 | 同上 |
| 问题清单 | 专家组综合线上评估和入校评估提出的问题清单；学校自评也形成自评问题清单 | 同上；各校撰写说明 |
| 整改方案、整改报告 | 评估结论反馈后30日内提交整改方案，原则上两年内完成整改并提交整改报告 | 同上（整改材料交 gongwen-rectify） |
| 状态数据 | 本科教学基本状态数据，经高等教育质量监测国家数据平台采集，生成《本科教学状态数据分析报告》 | 各校审核评估撰写说明；2023—2024学年各校质量报告的数据说明 |
| 质量监测数据采集 | 2025年首次通过国家教育大数据中心部校数据网络采集学科专业数据，分院校篇、专业篇、学科篇；采集结果是质量报告、评估、专业认证的数据依据 | 教督厅函〔2025〕16号（2025年，据高校转发的通知，十七大类153个表格以当年指南为准） |
| 五个度 | 培养目标的达成度、社会需求的适应度、师资和条件的保障度、质量保障运行的有效度、学生和用人单位的满意度 | 第一类“质保效果”、第二类“教学成效”的指标 |
| 必选定量指标 | 第二类指标体系中规定底线值的定量指标，如思政课专任教师与折合在校生比 | 第二类指标体系，以本省、本校采用的文本为准 |
| 学科评估 | 按一级学科对学科整体水平的评估，由学位中心组织；第五轮2020年启动 | 学位中心第五轮工作方案（2020年11月） |
| 代表作评价 | 第五轮科研评价凝练标志性成果、以代表性论文支撑，不以引用等计量指标为主要依据 | 第五轮指标体系框架说明 |
| 学位授权点合格评估 | 分专项合格评估（新增学位授权点授权满3年后接受）和周期性合格评估（每6年一轮）；周期性评估分单位自我评估和教育行政部门抽评两阶段，以自我评估为主 | 学位〔2020〕25号附件《学位授权点合格评估办法》第四条、第五条 |
| 自评节点 | 每轮第1年底前确认参评学位授权点并报省级备案，第5年底前完成自我评估，第6年抽评；第3年和第6年3月底前报送基本状态信息 | 同上第五条、第八条（六） |
| 两个年度报告 | 《研究生教育发展质量年度报告》和《学位授权点建设年度报告》，作为自我评估的重要环节，经脱密处理后在本单位网站发布 | 同上第八条（二） |
| 评估结果 | 自评和抽评结论为“合格”“不合格”；抽评不合格专家意见过半的建议撤销授权，三分之一至二分之一的限期整改（暂停招生） | 同上第十一条、第十三条 |
| 本科毕业论文抽检 | 每年一次，抽上一学年度授予学士学位的论文，比例原则上应不低于2%；每篇送3位专家，2位及以上评“不合格”认定为存在问题论文 | 教督〔2020〕5号（2020年12月24日）第四条、第十条（据中国政府网原文） |
| 学位论文抽检 | 博士、硕士学位论文抽检；评估周期内抽检问题较多的学位授权点，抽评时加大抽评比例 | 学位〔2014〕5号《博士硕士学位论文抽检办法》；学位〔2020〕25号附件第九条 |

## 二、教学与人才培养类

| 术语 | 解释 | 出处 |
|---|---|---|
| 以本为本 | 坚持本科教育在人才培养中的核心地位，是审核评估“本科地位”的审核重点 | 第二类指标“本科地位” |
| 四个回归 | 回归常识（学生刻苦读书学习）、回归本分（教师潜心教书育人）、回归初心（高等学校倾心培养社会主义建设者和接班人）、回归梦想（高等教育倾力实现教育报国、教育强国梦）；审核评估“本科地位”看推进四个回归的举措与成效 | 新时代全国高等学校本科教育工作会议（2018年6月）；第二类指标“本科地位”。写进正文的表述以用户提供的原文为准 |
| 一流课程、一流专业 | 国家级和省级一流本科课程、一流本科专业建设点 | 以教育部、省教育厅公布名单为准 |
| 本科教学质量报告 | 本科高校按学年发布的教学质量报告，每学年由教育督导部门发通知并附“基本要求”；内容含本科教育基本情况、师资与教学条件、教学建设与改革、专业培养能力、质量保障体系、学生学习效果、特色发展、需要解决的问题；数据取自本科教学基本状态数据库，与高基报表协调一致 | 2021—2022学年版为国务院教育督导委员会办公室的国教督办函〔2022〕34号；2023—2024学年版为教育部办公厅的教督厅函〔2024〕17号（均据各校转载件和质量报告的编制依据说明），发文机关各学年不同；发布时间按省级教育部门当年通知 |
| 毕业去向落实率 | 就业统计指标，按届统计 | 以学校就业部门当年上报口径为准 |
| 就业质量年度报告 | 高校每年年底前发布当年报告，发布后一个月内将电子版和网址链接报教育部；含基本情况、主要特点、相关分析、发展趋势、教育教学反馈五部分，数据由就业部门核定 | 教学厅函〔2013〕25号（2013年11月2日） |
| 教授为本科生授课比例 | 教授（副教授）主讲本科课程的比例 | 状态数据口径 |
| 修业年限 | 专科2至3年，本科4至5年，硕士研究生2至3年，博士研究生3至4年；非全日制可适当延长 | 《高等教育法》（2018年修正）第十七条 |

## 三、科研与学科类

| 术语 | 解释 | 出处 |
|---|---|---|
| 双一流建设 | 第二轮建设高校及建设学科名单由教育部、财政部、国家发展改革委公布；北京大学、清华大学自主确定建设学科并自行公布；第一轮受公开警示的学科须整改并在2023年接受评价。“建设高校”“建设学科”不写成“入选”“获批” | 教研函〔2022〕1号（落款2022年2月9日，2月14日对外公布，据中国政府网）；建设期限和动态调整以教育部文件为准 |
| 纵向项目、横向项目 | 纵向指政府部门、基金委等立项的项目；横向指企事业单位委托的项目 | 高校科研管理通行分类，以本校科研管理办法为准 |
| 到账经费、合同经费 | 到账指实际到校的经费；合同指合同或任务书约定的总额 | 同上 |
| 直接费用三大类 | 中央财政科研项目直接费用按设备费、业务费、劳务费编制；设备费预算调剂权下放项目承担单位，其他费用调剂权由承担单位下放项目负责人 | 国办发〔2021〕32号（2021年8月5日）第一部分 |
| 间接费用核定比例 | 按直接费用扣除设备购置费后核定：500万元以下部分不超过30%，500万至1000万元的部分不超过25%，1000万元以上的部分不超过20%；数学等纯理论基础研究项目可提高到不超过60% | 同上第三部分。适用中央财政科研项目，横向项目和地方项目按本校和项目方规定 |
| 项目承担单位法人责任 | 承担单位对经费使用和监督负主体责任；失信行为纳入信用记录 | 同上第六、七部分 |
| 活页 | 国家社科基金年度项目《课题论证活页》，用于匿名通讯初评 | 2026年国家社科基金年度项目申报公告（2026年5月6日） |
| 限项 | 申报和在研项目数量的限制规定 | 当年申报公告、项目指南 |
| 包干制、预算制 | 国家自然科学基金的两种资金管理方式；2026年青年科学基金项目（A、B、C类）和试点设立的青年学生基础研究项目实行经费包干制。中央财政科研项目的包干制主要在人才类和基础研究类项目推行 | 国科金发计〔2026〕2号一（二）2（据基金委通告转载件）；国办发〔2021〕32号 |
| 署名单位认定 | 成果按署名单位统计，不随人走 | 第五轮学科评估答记者问；《深化新时代教育评价改革总体方案》（2020年10月） |

## 四、学术规范与师德类

| 术语 | 解释 | 出处 |
|---|---|---|
| 学术不端行为 | 认定七类：剽窃抄袭侵占他人成果；篡改他人成果；伪造科研数据、资料、文献、注释，捏造事实、编造虚假研究成果；不当署名；在申报课题、成果、奖励、职务评审、申请学位中提供虚假学术信息；买卖论文、代写；其他依规则属于学术不端的行为 | 教育部令第40号（2016年6月16日公布，9月1日施行）第二十七条 |
| 情节严重 | 造成恶劣影响，利益输送或交换，打击报复举报人，有组织实施，多次实施，其他严重后果 | 同上第二十八条 |
| 学术不端的处理措施 | 通报批评；终止或撤销科研项目并取消申请资格；撤销奖励荣誉；辞退解聘；按规定给予处分；学生与学位相关的由学位授予单位暂缓授予、不授予或撤销学位 | 同上第二十九条 |
| 学术不端调查处理 | 调查期限自决定受理之日起6个月内完成，特别复杂的经批准可延长，一般不超过6个月；学术评议由学术委员会或不少于5人的专家组进行 | 教科信〔2024〕3号《高等学校学术不端行为调查处理实施细则》第十一条、第十五条（落款2024年3月26日，教育部办公厅2024年4月17日印发，据北京市教委转载页面；截至2026-11-04未查到同名的教科信〔2025〕3号）；指导意见见教科信〔2024〕2号 |
| 科研失信行为 | 高校等是科研失信行为调查处理的第一责任主体，自行细化受理举报、认定标准和调查程序 | 国科发监〔2022〕221号《科研失信行为调查处理规则》（科技部等二十二部门，2022年8月落款，替代旧试行规则） |
| 不授予、撤销学位 | 学位论文或实践成果存在代写、剽窃、伪造等学术不端的，经学位评定委员会决议，不授予或撤销学位；拟决定前须告知事实、理由、依据并听取陈述申辩 | 《学位法》（2024年4月26日通过，2025年1月1日施行）第三十七条、第三十九条 |
| 师德失范一票否决 | 年度考核、职称评聘、推优评先、表彰奖励中进行师德考核，师德失范实行一票否决；十项准则包括坚定政治方向、遵守学术规范、秉持公平诚信、坚守廉洁自律等 | 教师〔2018〕16号《新时代高校教师职业行为十项准则》（2018年11月8日） |
| 破“五唯” | 破除唯分数、唯升学、唯文凭、唯论文、唯帽子；职称评聘把师德表现放在首位，成果评价重质量贡献。写材料不用“论文数量大幅增长”当成效，改写代表性成果及其贡献 | 《深化新时代教育评价改革总体方案》（中共中央、国务院，2020年10月） |

## 五、招生与学位类

| 术语 | 解释 | 出处 |
|---|---|---|
| 特殊类型招生 | 自主选拔录取、艺术类、体育类、保送生等；招生违规的处理重点之一 | 教育部令第36号《普通高等学校招生违规行为处理暂行办法》（2014年7月8日）第六条第（五）项 |
| 招生工作问责 | 高校校长是招生工作第一责任人，对本校招生工作负全面领导责任 | 同上第十二条 |
| 硕士研究生招生管理规定 | 教育部每年印发《全国硕士研究生招生工作管理规定》；2027年招生的报名、初试时间见 `references/calendar.md` | 新华社2026年9月24日稿（科技日报等转载） |
| 学位评定委员会 | 作出授予或撤销学位决议，处理学位争议；人数为不少于九人的单数，主席由单位主要行政负责人担任 | 《学位法》第九条、第十条 |
| 学位质量评估 | 国务院教育行政部门和省级学位委员会定期评估学位授予单位和学位授权点，不能保证质量的限期整改，严重的撤销授予资格 | 《学位法》第三十四条 |

## 六、学生工作类

## 七、管理与程序类

| 术语 | 解释 | 出处 |
|---|---|---|
| 党委领导下的校长负责制 | 国家举办的高校实行党委领导下的校长负责制；党委统一领导学校工作，支持校长独立负责地行使职权 | 《高等教育法》（2018年修正）第三十九条；《中国共产党普通高等学校基层组织工作条例》（2021年）第三条 |
| 党委任期 | 高校党委每届任期5年；院系党的基层委员会每届任期一般5年 | 同条例第五条、第七条 |
| 党政联席会议 | 院系讨论和决定本单位重要事项的会议；涉及办学方向、教师队伍建设、师生员工切身利益的事项，先经党组织研究讨论再提交联席会议决定；干部任用、党员队伍建设等由党组织会议研究决定 | 同条例第十一条 |
| 学术委员会 | 审议学科建设、专业设置和教学科研计划，评定成果，处理学术纠纷，调查认定学术不端行为，学术事务先经其审议 | 《高等教育法》第四十二条；《高等学校学术委员会规程》（教育部令第35号，2014年） |
| 教代会 | 每学年至少召开一次；听取学校发展规划、年度工作报告并提出意见建议，讨论通过与教职工利益直接相关的方案 | 《学校教职工代表大会规定》（教育部令第32号，2011年12月）第七条、第十七条 |
| 两委工作报告 | 党代会上的党委工作报告和纪委工作报告 | 以学校党委召开大会的通知和议程为准 |
| 签报、请示报告单 | 学院、部门向校领导请示事项的内部上行文 | 各校签报制度，见 `references/_shared/rules/doc-types.md` 第三部分 |
| 部门公文 | 职能部门在职权内向校内单位发的公文，部门负责人签发 | 各校公文处理办法 |
| 教育统计资料 | 上报资料须统计人员、审核人、本单位负责人签名并盖章，对真实性负责；学校及其负责人不得自行修改统计资料，不得要求伪造、篡改 | 教育部令第44号《教育统计管理规定》（2018年）第二十七条、第三十二条 |
| 国家秘密、科技保密 | 禁止使用非涉密信息系统、设备存储或处理国家秘密，禁止在互联网传递；涉密人员发表论文、申请专利、学术交流前须保密审查；涉密项目各层级签保密责任书 | 《保守国家秘密法》（2024年2月27日修订，2024年5月1日施行）第二十九条、第三十一条；科技部、国家保密局令第16号《科学技术保密规定》（2015年）第二十九条、第三十四条 |
