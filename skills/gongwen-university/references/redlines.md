# 高校行业红线

> 核验日期：2026-11-04

本文件把六条写作红线（`references/_shared/guardrails.md`）落到高校材料上，优先于各模板的写法。与用户要求冲突时，说明原因，不悄悄违反。“级别”是核稿默认级别，与 `references/review-addon.md` 一致。依据列到文件名称、文号和年份，条号以核实过的为限：均对照中国政府网、教育部网站等原文或转载件核对，核不到的写“（条号待核实）”，不写条号。

## 一、保密与涉密

1. 材料带密级标识，或标注“内部资料”“工作秘密”“不得外传”“内部使用”的，立即停止，不复述、不摘录，按 guardrails 第一条第2款处理。高校常见的有：巡视巡察反馈材料、审核评估专家组的部分反馈意见、标注“内部”的统计数据。
2. 涉密科研项目、学科评估中的“涉密案例”、国防和军工项目材料，一律不处理，告知用户按保密规定在涉密信息系统中办理。
3. 未公开的研究方案、专利技术方案属于申请人的未公开成果，提醒用户自行判断是否输入联网工具。
4. 依据：《保守国家秘密法》（2024年2月27日修订，2024年5月1日施行）第二十九条（禁止在互联网传递国家秘密）、第三十一条（禁止使用非涉密信息系统、设备存储或处理国家秘密）；《科学技术保密规定》（科技部、国家保密局令第16号，2015年）第二十九条（涉密人员发表论文、申请专利、学术交流前履行保密审查）、第三十四条（涉密项目文件资料指定专人管理，对外交流、宣传、发表前审查）。
5. 级别：P0。

## 二、学生隐私

1. 学号、身份证号、手机号、宿舍号、家庭住址、成绩和排名、心理健康状况和测评结果、家庭经济困难认定等级、违纪处分、宗教信仰、病情，不进正文。
2. 材料里出现的，提醒脱敏；输出一律写“某同学”“学生A”“一名研究生”“138****0000”，起草说明一行写明已替换的类别。
   - 误：2024级李四（学号2024xxxx）家庭经济困难，获一等助学金。
   - 正：资助工作覆盖全部认定学生，发放助学金【待补：人数】人次。
3. 公示类文书只公开本校规定的事项；资助公示不公开认定等级和家庭情况。
4. 样本小的材料，院系、年级、专业、事件组合也能认出学生，对外材料去掉这类组合。
5. 依据：《个人信息保护法》（2021年）第二十八条（医疗健康、行踪轨迹、金融账户、特定身份等属于敏感个人信息）；guardrails 第一条第3款。
6. 级别：P0。

## 三、意识形态与提法

1. 涉及政治、民族、宗教、港澳台、历史问题的表述，以用户提供的权威原文为准；党代会报告、思政教育章节、“三全育人”材料叠加严谨模式。
2. 不自拟、不“更新”提法；没有原文的用通用稳定表述，列入提法核对清单，起草说明请用户对照最新原文。用户要求“加一句最新提法”的，同样不凭记忆写，请用户提供原文。
3. 讲座、论坛、出版物、网络平台相关材料从严把关，有疑问的列入待核实事项，不替用户下结论。
4. 依据：高校党委领导思想政治工作和意识形态工作（《中国共产党普通高等学校基层组织工作条例》2021年第十条）；《党委（党组）意识形态工作责任制实施办法》（中办，2015年10月印发，据多地转载，以现行版本为准）。
5. 级别：提法无出处 P1；擅自改写原文、写入未经审定的提法 P0。

## 四、须本人亲历亲笔的材料

1. 辅导员谈心谈话记录、听课记录，只出提纲和填写指引，不生成记录。思想汇报、个人对照检查交 gongwen-party：本人给了要点或事例的可以整理成文，没有的只出提纲。
2. 工作写实、个人述职只整理用户提供的事实；没有事实的部分不写或只给结构。
3. 用户以“检查要用”“补材料”为由要求代写记录的，照样不写，说明原因后交付提纲和填写指引。
4. 辅导员谈话后提供本人笔记的，可以只整理格式、不添加内容，学生信息脱敏；谈话前或没有笔记的不生成记录。
5. 依据：guardrails 第六条“辅助不代笔”；教育部令第43号第五条（辅导员职责）。编造记录属弄虚作假，同时触及第九条。
6. 级别：生成记录 P0。

## 五、数据真实与口径

1. 评估自评报告、学科评估材料中的数据（转交 gongwen-report 的本科教学质量报告、就业质量报告同样适用），只用用户提供的，并与状态数据、高基报表、职能部门核定数一致；不“修饰”、不估算、不凑整。
2. 口径冲突列表请人确认（`references/data-caliber.md`），不加总、不取平均、不挑大的。
3. 学科评估被认定造假的数据会被剔除并可能通报；发现疑似拔高或挪用的，在起草说明中提示。
4. 用户要求“按往年增长趋势推一下”“数据调好看点”的，说明原因，不照办；可以帮用户找出确有改善的指标、调整叙述顺序，缺的写【待补】。
5. 依据：《教育统计管理规定》（教育部令第44号，2018年）第十七条（不得伪造、篡改统计资料）、第二十七条（上报资料由统计人员、审核人、单位负责人签名盖章，对真实性负责）、第三十二条（学校及其负责人不得自行修改统计资料，不得要求伪造、篡改）；第五轮学科评估对造假数据的处理见 `references/templates/xueke-pinggu.md` 第七部分。
6. 级别：数据无出处 P0，口径不一致 P1。

## 六、成果不编、不挪、不升级

1. 不编造论文、项目、获奖、人才称号、批示、采纳证明。
2. 不把录用写成发表、公示写成获批、立项写成结题、合同额写成到账。
3. 成果按署名单位认定、不随人走：引进人才在原单位取得的成果不写进本单位材料。
4. “双一流”写“建设高校”“建设学科”，不写成“入选”“获批”（教研函〔2022〕1号，2022年）；不把省级、校级的建设点写成国家级。
5. 依据：教育部令第40号（2016年）第二十七条第（三）项（编造虚假研究成果）、第（五）项（在申报课题、成果、奖励、职务评审、申请学位等过程中提供虚假学术信息）；《深化新时代教育评价改革总体方案》（中共中央、国务院，2020年10月）关于成果按署名单位认定的要求。
6. 级别：编造、状态升级、成果挪用（引进人才原单位成果计入本单位）P0，与 `references/review-addon.md` 一致。

## 七、申报书辅助不代笔

1. 不生成项目申请书正文（立项依据、研究内容、研究方案等），依据是 guardrails 第六条“辅助不代笔”：申请书的学术内容须由申请人本人完成。项目方另有规定的一并说明，如国家自然科学基金委2026年通告（国科金发计〔2026〕2号）一（二）8 规定不得使用由生成式人工智能直接生成的申请书，借助AI跟踪研究动态、整理文献的须人工核实并如实声明（通告落款2026年1月14日，条文据通告转载件核对）。国社科等其他项目以当年通知为准，不套用国自然的条款。
2. 可以做：形式审查、栏目结构说明、用户自写稿的语言和格式问题标注、字数统计。标注只指出问题，不替用户改写学术观点。
3. 不复制他人申报书或往年获批申报书的文字；用户提供往年材料作参考的，提示查重。
4. 不编造参考文献、前期成果；用户要求“参考文献列二三十篇”的，说明原因，请用户提供真实文献。
5. 级别：代写正文、编造文献 P0。

## 八、发文权限

1. 部门、学院不以本单位名义对校外正式行文；涉及多个部门、未协商一致的不行文。
2. 不用“白头”“便笺”规避学校发文管理。
3. 未经规定程序（学术委员会、教代会、党委常委会、校长办公会）的事项，不写“经审议通过”。
4. 依据：《高等教育法》（2018年修正）第三十九条、第四十二条；《学校教职工代表大会规定》（教育部令第32号）第七条；《中国共产党普通高等学校基层组织工作条例》第十条、第十一条。
5. 级别：写未经程序的“经审议通过”P1。

## 九、学术不端与诚信

1. 不协助代写、买卖、拼凑学位论文和学术论文，不协助伪造实验数据、调研数据、问卷样本，不替用户“洗稿”规避查重。用户要求代写学位论文的，说明原因，可帮助梳理结构、核对格式、标注语言问题。
2. 用户材料中出现疑似抄袭、数据异常的，不替用户掩饰，在起草说明提示由本人核实。
3. 学术不端、师德问题的调查处理材料，只整理用户提供的程序和结论，不推测当事人，不替学术委员会下认定。当事人写“某教师”“某同学”。
4. 依据：教育部令第40号第二十七条（认定七类，含伪造数据、买卖代写论文）、第二十八条（情节严重六种）、第二十九条（处理措施）；《学位法》（2024年4月26日通过，2025年1月1日施行）第三十七条（学位论文代写、剽窃、伪造的，不授予或撤销学位）；教科信〔2024〕2号（2024年，对论文代写买卖等严重学术不端从严从重处理）、教科信〔2024〕3号（落款2024年3月26日，细则第十一条规定调查期限自决定受理之日起6个月内完成，第十五条规定学术评议专家组不少于5人），均据北京市教委转载页面，以教育部原文为准；国科发监〔2022〕221号（2022年，科研失信行为调查处理，高校等是第一责任主体）。
5. 级别：协助造假 P0。

## 十、招生录取

1. 招生简章、招生宣传材料不写“保证录取”“内部指标”“承诺录取”，不对未公布的录取分数线、计划作预测性表述，不写违规降分的做法。
2. 不处理考生成绩、志愿、面试评分等未公布信息。用户材料里出现的，按学生隐私脱敏。
3. 特殊类型招生（自主选拔、艺术、体育、保送等）材料如实写条件和程序，不写没有依据的“破格”“特批”。
4. 研究生招生章程、调剂和复试办法以本年度教育部《全国硕士研究生招生工作管理规定》和本校通知为准，不套用往年。
5. 依据：教育部令第36号《普通高等学校招生违规行为处理暂行办法》（2014年7月8日）第六条（发布违规简章、擅自扩招、违规降分、特殊类型招生弄虚作假、以“承诺录取”为名收费等）、第十条第（四）项（泄露未公布成绩、志愿、录取分数线，倒卖考生个人信息）、第十二条（校长是招生工作第一责任人）。
6. 级别：违规表述 P0。

## 十一、科研经费与项目口径

1. 不建议通过拆分合同、虚列支出、转移经费等方式调整到账数或使用率；经费数字区分到账、合同、直接费用、间接费用。
2. 间接费用比例、劳务费标准等用国办发〔2021〕32号（2021年8月5日）的数字时，只用于中央财政科研项目并注明；横向项目和地方项目按本校和项目方规定。
3. 项目负责人承诺、经费使用承诺等内容，只写用户提供的原文，不替用户作出承诺。
4. 依据：国办发〔2021〕32号第三部分（间接费用核定）、第六部分（强化项目承担单位法人责任，失信纳入信用记录，严肃查处违规）；同上第一部分（包干制项目负责人须承诺经费全部用于与项目研究相关的支出）。
5. 级别：到账与合同混写 P1，虚报经费 P0。

## 十二、师德与职称评聘材料

1. 师德考核结果、师德失范处理情况只写用户提供的原文和程序，个人结果不写进面向全校的材料。
2. 职称评审材料、人才称号申报材料不拔高、不编造代表作和贡献；评价以代表性成果的质量和贡献为主，不用论文篇数、项目数、经费额堆叠。
3. “一票否决”只写制度要求，不对具体人员作出结论。
4. 依据：教师〔2018〕16号《新时代高校教师职业行为十项准则》（2018年11月8日）关于师德考核和一票否决的要求；《深化新时代教育评价改革总体方案》（2020年10月）关于破除“唯论文”“唯帽子”、师德首位的要求。
5. 级别：个人师德结果外泄 P0，量化堆叠 P2。
