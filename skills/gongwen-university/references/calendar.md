# 高校写作日历

> 核验日期：2026-11-04

按月份提示本包文书的常见节点。具体日期以当年上级通知和学校安排为准；本表中的具体日期只列已对照官方来源核实的2026年数据（示例，用于判断大致节点，引用时标“据本包资料”），其他年份不套用。通用节点（开学、毕业典礼讲话、工作要点等）见 `references/_shared/profiles/units/gaoxiao.md` 第七部分，相应文书交核心 skill。

| 时间 | 本包相关文书 | 说明 |
|---|---|---|
| 1月 | 学院年度工作总结（收尾）、辅导员学期工作写实 | 学校年度考核多在12月至次年1月 |
| 12月至次年1月 | 高等教育质量监测数据采集（状态数据口径的来源，自评报告、质量报告对账用） | 2025年为首次通过国家教育大数据中心部校数据网络采集学科专业数据，教督厅函〔2025〕16号，集中采集至2026年1月15日（据高校转发的通知，当年时间以教育部通知为准） |
| 2—3月 | 国家自然科学基金申报书形式审查 | 2026年集中接收期为3月1日至3月20日16时（国科金发计〔2026〕2号），依托单位校内截止时间更早 |
| 3月底 | 学位授权点周期性合格评估的基本状态信息报送 | 每轮周期性评估的第3年和第6年3月底前，向国务院学位委员会办公室报送参评学位授权点截至上一年底的基本状态信息（学位〔2020〕25号附件第八条（六），据教育部网站文本） |
| 3—4月 | 教代会学校工作报告提纲 | 教代会每学年至少召开一次（教育部令第32号第十七条），时间以学校安排为准 |
| 5—6月 | 国家社会科学基金年度项目申报书和活页形式审查 | 2026年公告发布于5月6日；申报系统5月29日零时至6月7日17时开放；省级社科规划办或北京委托管理机构的线上审核6月15日17时前完成；纸质申请书7月5日前送达全国社科规划办（全国哲学社会科学工作办公室《2026年国家社会科学基金年度项目申报公告》）。单位内部审核早于此，以科研处通知为准 |
| 6—7月 | 辅导员毕业生离校谈话提纲；学院学期总结 | 以学校安排为准 |
| 8月下旬 | 国家自然科学基金集中接收期项目的资助结果公布，校内项目统计、成果状态更新（立项不写成结题） | 2026年为8月26日公布（据科技日报2026年8月26日报道）；以当年通知为准 |
| 9月 | 新生入学谈心谈话提纲；教育事业统计 | 迎新后集中开展，以本校学生工作要求为准；教育事业统计的统计时点为学年初，即每年9月1日（《教育事业综合统计调查制度》国统制〔2021〕135号指标解释，据北京市教委转载页面），填报时间以当年通知为准 |
| 10月 | 研究生招生简章、宣传材料检查（红线见 `references/redlines.md` 第十条） | 2027年全国硕士研究生招生：预报名2026年10月9日至12日，正式报名10月15日至24日，初试12月19日至20日（据新华社2026年9月24日稿，科技日报等转载）；复试、调剂安排以教育部和各校当年通知为准；各省安排以省级招生考试机构公布为准 |
| 10—11月 | 本科教学质量报告（交 gongwen-report，数据按 `references/data-caliber.md` 对齐状态数据口径） | 每学年由教育督导部门发通知并附基本要求，发文机关各学年不同（2021—2022学年版为国务院教育督导委员会办公室的国教督办函〔2022〕34号，2023—2024学年版为教育部办公厅的教督厅函〔2024〕17号，均据各校转载件），以当年通知为准；数据取自本科教学基本状态数据库，发布时间按省级教育部门当年通知 |
| 12月 | 学院年度工作总结、辅导员年度工作写实 | 以学校年度考核通知为准 |
| 12月 | 毕业生就业质量年度报告（交 gongwen-report，数据以就业部门核定为准） | 高校每年年底前发布当年报告，发布后一个月内将电子版和网址链接报教育部（教学厅函〔2013〕25号） |
| 每年 | 本科毕业论文（设计）抽检、学位论文抽检的迎检说明 | 本科抽检每年一次，抽上一学年度授予学士学位的论文，比例原则上应不低于2%（教督〔2020〕5号第四条，据中国政府网原文）；具体时间由省级教育行政部门通知。研究生学位论文抽检见学位〔2014〕5号 |
| 按周期 | 审核评估自评报告 | 每5年一个周期；2021—2025年一轮按教督〔2021〕1号，2026年起新一轮截至2026-11-04未查到教育部方案，以教育部方案为准；评估前一年多开始自评 |
| 按周期 | 学科评估材料 | 第五轮2020年启动；第六轮截至2026-11-04未查到学位中心正式工作方案，以学位中心工作方案为准 |
| 按周期 | 学位授权点周期性合格评估（自评总结报告、两个年度报告） | 每6年一轮：第1年底前确认参评点，第5年底前完成自我评估，第6年教育行政部门抽评（学位〔2020〕25号附件第五条，据教育部网站文本）；下一轮起止以学位办和省级学位委员会通知为准 |
| 按周期 | 党代会报告提纲 | 高校党委每届任期5年（《中国共产党普通高等学校基层组织工作条例》第五条，以上级换届部署为准） |
| 随时 | 校内请示（签报）；发文主体判断（部门公文起草交 gongwen-draft） | 按需 |

使用规则：
1. 用户问“最近要准备什么”的，按当月给2至3项，注明“以当年通知为准”。
2. 不报未核实的具体截止日期；本表没有的项目（教育部人文社科项目、省级项目等）提示用户以当年申报通知为准。
3. 本表列出的2026年日期是示例，非2026年的用户按当年通知；用户给了学校内部日程的，以学校日程为准。
