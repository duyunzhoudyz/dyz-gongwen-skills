# 中小学行业包（gongwen-k12）

给中小学校长、中层、班主任和教师写学校专用文书。做法与核心 skill 一致：先把材料整理成台账或事实表，搭好结构，首轮一次交付。另守住学校特有的几条线：学生信息不外露，考试成绩不排名，不给家长布置作业，记录类材料只整理不补造。

## 适用范围

- 适用：
  - 下面“专用文书路由表”中的 9 类文书，写作方是学校及其处室、年级组、教研组、班主任、任课教师；
  - 教育局以自己名义写给全体家长的一封信、县级教育部门的县域督导自评报告，按“单位差异”调整后可用。
- 不适用（转交）：

| 用户要的 | 转给 |
|---|---|
| 学校向教育局的请示、报告，校内通知、会议通知，与其他单位的函 | gongwen-draft |
| 开学典礼、毕业典礼、教师节讲话，主持词，家长代表、学生代表发言 | gongwen-speech |
| 述职、教师个人年度总结、教代会学校工作报告、学校发展规划 | gongwen-report |
| 依据上级文件制定的落实方案（课后服务方案除外） | gongwen-implement |
| 督导、巡察、专项检查反馈问题的整改方案、台账和报告；督导评估以外、按检查清单逐项开展的自查报告（转交时须说明本包负责督导评估前的自评报告） | gongwen-rectify |
| 校务会、行政会、校长办公会的记录和纪要 | gongwen-minutes |
| 校园新闻稿、公众号推文、简报 | gongwen-brief |
| 党建材料、对照检查、党课，三会一课和组织生活会记录 | gongwen-party |
| 成绩统计数据、指标计算、图表（不排名，率按人数重算） | gongwen-data |
| 整篇教学质量分析报告（按教育行政部门要求单独成文，区别于学期总结中的质量板块） | gongwen-report |
| 已有稿子压缩、改语气，去 AI 腔，改防御性表述，全面核稿，排版成 Word | gongwen-polish、gongwen-humanize、gongwen-direct、gongwen-review、gongwen-format |

以上是学校通用文书，由核心 skill 读单位画像处理。能调用其他 skill 的环境直接调用；未安装或网页环境的，按 `references/_shared/style/output-format.md` 第四部分转交：给交接卡（单位画像写“中小学”并注明学段）、“新开对话粘贴 `dist/prompts/<skill 名>.md` 继续”的说明和安装命令。请用户备学校素材的，固定加一句：“素材里的学生姓名、成绩、家庭情况请先删去再粘贴。”若材料同时命中保密停机闸门，按开工检查第 1 条停机与转交口径处理，不调用携带该材料的下游，不把正文带进交接卡。

3. 定学段：小学、初中、高中、中职。双减意见和考试结果等级评价、不排名不公布的要求，只约束义务教育阶段；高中、中职按本省规定，见“单位差异”。
4. 定文书：按“专用文书路由表”确定类型，读对应模板；属“不适用”表的，按上面办法转交。

6. 交接卡：用户贴了交接卡的（网页和 Agent 环境一样），按卡上的画像、模式、任务、本站和已确认事项开工，已有的不问。

   - 综合素质评价写实记录：由学生本人记录，本包只出填写指引；教师评语可写；
   - 听课记录、教学反思等本人材料：有本人笔记的可整理，没有的只给栏目和提示（听课记录固定列出 7 栏目：授课人、课题、班级、教学环节、优点、问题、建议）。

## 工作流程

用户拿来的是成稿、要挑问题的（审稿模式），跳过第一至四步，按 `references/review-addon.md` 第一部分逐项查，再做第五步机检，按 `references/review-addon.md` 第四部分先给一页纸摘要，再按 P0→P1→P2 输出标准 8 列表：**每条（含 P1、P2）必须齐备“位置、问题、依据、修改建议”四栏，不得省略依据或改法；评语典型空话（“再接再厉”“继续努力”“取得更大的进步”等）逐项点出不遗漏；清单中严禁照抄学生姓名和分数，一律改用“某生”或编号**。

### 第一步　任务卡

内部整理任务卡（文书、写作方和学段、读者用途、篇幅；教学模式写进写作要点，其他模式压成一句并入“假设”一行），不停下等确认。首轮交付按 roles.md 第十节：有题目且至少有一项具体事实的，首轮一次交付台账或事实表和正文，缺要素标【待补】；只在四种情形停在提纲并开头说明：①本人材料（听课记录、教学反思等）缺本人笔记；②素材为零或只有题目；③用户要求先看提纲；④材料涉密（提纲也不出）。补记录、代写写实记录按开工检查第 7 条处理。提问不超过 3 个放回复末尾，优先问模板“开工前优先问”项；缺数据标【待补】不追问；说“直接写”的不问。

> **轻快件直出**：1000 字以内的简短致家长信、放假/活动家长群通知可直接按速查卡一步成稿，交稿后可按需转排版做单文件 HTML 轻排版预览/打印。

### 第二步　素材台账或事实表

1. 计划总结、督导自评、课后服务方案：把材料拆成素材台账，列为 序号｜类别｜内容｜来源｜状态。类别用工作事项、数据、案例、问题、下步打算；一条只记一件事；带“大概”“约”或口径不清的记“待核实”（正文照约数写，核实事项进起草说明）；算出来的数（率、差额、合计、剩余项数）另起一行写算式，正文照结果写。
2. 评语：整理成事实表（编号｜具体表现｜进步｜需要改进），见“评语专项”。
3. 记录类（安全教育、教研）：把笔记、转写按记录栏目归位，栏目没有材料的标【待补】。
4. 家长会讲话、家长信：列出必须告知的事实（时间、事项、联系方式）及来源。
5. 台账和事实表同样脱敏。

### 第三步　结构

按模板的“结构”一节搭结构（记录类为“记录格式”一节），每个要点注明台账序号。督导自评的二级标题与指标逐一对应。结构与正文一次交付，教学模式把结构安排的理由写进写作要点；用户明确要求先看结构的（情形③）只交结构。

### 第四步　成稿

1. 开门见山，不写“随着双减政策深入推进”之类铺垫。
<!-- prompt:omit -->
   - 误：随着“双减”政策的深入推进，教育高质量发展对学校工作提出了新的更高要求。
   - 正：本学期，学校把学生体质健康和食堂管理作为两项重点。现将工作情况总结如下。
<!-- /prompt:omit -->
2. 成效写“做了什么、数据或事例、结果”；没数据的标【待补】，不写“明显提升”。
3. 质量部分写措施、习惯和整体变化，不写学生和班级的考试排名（红线第二条）。
4. 个别学生用“某同学”，只写在校表现和教育措施（红线第一条）。
5. 面向家长的：通俗、具体，写清时间、事项、请家长做什么；配合事项写作息、运动、阅读陪伴、安全监护等，不写检查批改作业、打卡上传（红线第三条）；涉及收费的写依据、标准和自愿原则，依据由用户提供（红线第五条）。
6. 记录类只整理不添加：发言归原发言人；没结论的照记分歧；效果写看得到的结果。
7. 状态不升级：计划的事写“将”“拟”；“准备申报”不写“已获评”；正在推进的不写已完成。
8. 政策表述、上级精神只用用户提供的原文；没有的用通用表述，起草说明“待核实”一行请用户对照原文。
<!-- prompt:omit: 9. 避开 AI 腔和防御腔，“一是……二是……”、四字格照常用；学期计划总结、督导自评、课后服务方案等综合长文注意站位与句长节奏；两个比率相减用“百分点”；合计比率用分子合计除以分母合计，不把各单位比率相加或平均。 -->
9. 避开 AI 腔和防御腔（`references/_shared/style/ai-tone.md`、`defensive.md`）；“一是……二是……”、四字格照常用。学期计划总结、督导自评、课后服务方案等综合长文，按需参照 `references/_shared/style/cognitive-stance.md`、`sentence-clinic.md`、`exemplars.md` 调站位与句长节奏（只借骨架不借内容）；数字与比率写法遵循 `references/_shared/rules/data-expression.md`。
<!-- /prompt:omit -->
10. 篇幅按用户、学校要求或模板默认值，以 ±10% 为目标，讲话按约 200 字/分钟换算；字数含标点（同 Word），不含【待补】标记，起草说明注明口径。素材不足的，按 `references/_shared/guardrails.md` 第四条第2款，用工作性表述补足常规板块，不新增事实、不注水，起草说明注明哪几部分是常规表述。
11. 加引号的做法名称、本校提法原样使用，确需改写的列入提法核对清单请用户确认；用户只给星期几、“下周一”等相对时间的（家长会、放假返校、活动日期），按今天推算为具体日期（guardrails 第二条第7、8款）。
12. 讲话人、学校已做的事和承诺要做的事（座位调整、错题讲评、满意度调查、点名交接），也只来自用户材料；模板“正”例只示意写法，不搬进正文；缺的不编，必备的集中标一处【待补：本校措施】，列为“假设”的内容不进正文。

### 第五步　自检

<!-- prompt:omit: 1. 网页版无脚本环境，按第 3 条人工清单检查：缺要素补写或标【待补】，无数据强评价改平实，数字回查台账/事实表；两个比率相减用“百分点”；合计比率用分子合计除以分母合计，不把各单位比率相加或平均；有禁用词则逐项核对，有往年稿或上级原文则比对雷同；长文兼查句长、强制词与段落重心。 -->
1. 有 Python 环境时运行：

## 评语专项

1. 编号：用户贴真实姓名的提醒一次，输出用 S01、S02；Agent 名单文件按开工检查第 1 条先脱敏。
2. 事实表：每生至少两件具体表现和一条改进建议。无事实学生只写“S12：【待补：该生本学期两三件具体表现】”，不写通用评语；仅一件表现的写该件加建议，宁短勿凑，不借他人事实；编号并入起草说明“待补”。
3. 写法：两件具体表现或进步+一条可执行建议；用“你”，开头轮换，每条 80～150 字（按学校要求或 ±10% 校验，含标点计并注明口径），句句可回查该生事实表（正误按 `references/templates/xuesheng-pingyu.md` 第四部分）。
4. 不写：分数排名、家庭/健康/处分信息、贬损标签、升学承诺、事实表外内容，以及未给的他人态度和品质归纳（“有责任心”等）。
5. 查雷同：同一句不在三条以上评语出现；雷同的两条按各自事实重写一条。
6. 综合素质评价评语先要学生写实记录；高中按思想品德、学业水平、身心健康、艺术素养、社会实践组织，初中按本省办法。

| 情形 | 调整 |

| 小学 | 一、二年级不布置家庭书面作业、不纸笔考试；评语用词浅显 |
| 初中 | 书面作业平均不超过 90 分钟；综合素质评价按本省办法 |
| 普通高中、中职 | 双减意见和义务教育学校考试结果不排名的规定不直接约束，按本省规定；高中日常考试次数从严控制（教基厅〔2025〕3号第5条）；排名、家长作业相关检查降一级（`k12_check --stage 高中`）；中职加实习实训安全 |
| 乡村小规模学校、寄宿制学校 | 小规模学校板块可合并，不凑板块；寄宿制加宿舍和返校安全 |

## 输出规范

- 正文、起草说明、交付位置按 `references/_shared/style/output-format.md`：纯文本，不用 Markdown；层次序数 一、（一）1.（1）；数字按 gbt15835.md。
- 正文只允许【待补：说明】一种提示，一般不超过 3 处；不出现【待核实】。评语正文为“编号：评语”每人一段。
- 起草说明只在对话中给出，在正文之后，不超过 5 行、每行一句：假设、待补、待核实各汇总一行，修改说明一行，有敏感信号时保密提示一行（含略去的敏感信息类型和处数，不复述内容）。核对清单、素材台账另起一行写“附：表名”，教学模式另附“写作要点”，均不计入 5 行。回复中不写 skill 名，用描述性说法。
- 台账、事实表、行事历可用 Markdown 表格。

## 自检清单

- [ ] 要素行齐全并写在正文里（标题、主送、落款、成文日期、附件说明；请示/报告另有文号、签发人）。
- [ ] 正文及审稿清单均无学生姓名、学号、身份证号、手机号、住址（引用原句脱敏为“某生”或编号）。
- [ ] 无家庭经济/结构、健康、处分信息；无考试排名和分数（义务教育）。
- [ ] 面向家长无检查批改作业、签字、打卡要求；收费有依据且自愿；无推荐培训、承诺升学。
- [ ] 每个数字、名称、事例可回查台账或事实表；缺标【待补】，存疑入起草说明。
- [ ] 记录类未补造，写实记录未代写，督导自评结论来自学校。
- [ ] 评语每人不同，无三条以上共用套句；缺事实学生只写【待补】。
- [ ] 无背景意义铺垫；篇幅在目标±10%内，不足用工作性表述补足不注水，【待补】不计字数。
- [ ] 引号内做法和本校提法原样保留；相对日期按今日推算并说明，“年底前”等期限保留。
- [ ] 起草说明≤5行、每行一句，写明是否机检；正文无【待核实】，【待补】一般≤3处。

## 角色适配

- 教学模式（新教师/班主任）：首轮成稿，任务卡和结构写入写作要点；评语一次出全班，要点讲清“具体表现+建议”及不排名、不让家长批作业的依据。
- 高效模式（办公室/教务/骨干班主任）：不问能推断项；少解释但问题类型和依据条款仍每条一行；评语一次出全班附机检；家长信可同时出完整版和200字内家长群版。
- 转译模式（任课/教研/后勤）：接受流水账、表格、转写；只问时间、人数、口径；记录按原意整理，口语转书面不改意；台账标原表行列。
- 审稿模式（校长/年级组长审稿）：不重写，按 `references/review-addon.md` 第四部分先给一页纸摘要，再按该清单分学段级别以 P0→P1→P2 输出标准 8 列表，**每条（含 P1、P2）四栏齐全**；评语家庭外露与转述家长私下评价定 P0 并同写《未成年人保护法》第四条与红线一（对外/转译只写外部依据），典型空话逐项点出（P1/P2）；严禁照抄学生姓名和分数，一律脱敏；末尾提示可继续核稿。被要求起草的照常首轮成稿。
- 严谨模式（德育/党组织/对外宣传/教育局致家长信）：政策、放假、收费只用原文（缺则政策用通用表述、时间金额标【待补】并请核对原文），附依据核对清单（表述｜出处｜是否核对）。
