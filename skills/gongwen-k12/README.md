# 中小学行业包（gongwen-k12）

> 版本 1.1.0　成熟度：Stable（稳定版）

给中小学校长、中层干部、班主任和任课教师用的写作助手，专写学校里特有的材料：学期计划总结、督导自评、班主任计划总结、家长会讲话、学生评语、安全教育记录、致家长的一封信、教研活动记录、课后服务方案。

它先把你给的材料整理成台账或事实表，再搭结构，第一轮就交完整的稿子。必须由你提供的数据缺了标【待补】，不替你编；要问的问题（最多 3 个）放在回复末尾，不耽误出稿。学校材料的几条线它会替你守住：学生信息不外露，考试成绩不排名，不给家长布置作业，没开展过的活动不补记录。

## 能做什么

| 文书 | 说明 |
|---|---|
| 学期工作计划和总结 | 学校、处室、年级组、教研组；按德育、教学、教师队伍、安全、家校协同组织，计划带行事历 |
| 督导评估自评报告 | 按督导指标逐项写达成情况和佐证材料，附佐证材料清单；自评等级由学校定。县级教育部门的县域优质均衡自评也能写 |
| 班主任工作计划和总结 | 具体到本班；个别学生只写在校表现和教育措施 |
| 家长会讲话稿 | 按讲话时长控制字数（约每分钟200字），口语化；不点名、不公布成绩 |
| 学生评语 | 期末评语、综合素质评价教师评语；每人按事实写，查雷同；用编号代替姓名 |
| 安全教育记录 | 安全班会、安全教育课、疏散演练；只整理已开展的活动 |
| 致家长的一封信 | 寒暑假、开学、专项安全提醒、课后服务告知；可加家长群短信版 |
| 教研活动记录 | 集体备课、听课评课、主题研讨；发言归属准确 |
| 课后服务方案 | 自愿参加、作业辅导和素质拓展、考勤交接、经费依据 |

## 你可以这样说

1. “期末了，帮我给班上42个孩子写评语，每个孩子的情况我列在表里了。”
2. “下周三开家长会，我是初一班主任，要讲10分钟左右，帮我弄个发言稿。”
3. “市里要来做办学水平督导，这是评估细则和各处室交上来的材料，帮我写个自评报告。”
4. “寒假快到了，以学校名义给家长写封信，提醒一下安全。”
5. “这是上周英语组听课评课的笔记，帮我整理成教研活动记录。”

## 输入

- 必需：你手头的素材。工作记录、处室报上来的情况、学生情况表、录音转写、上级通知都可以，不用先整理。
- 最好说明：写给谁、谁来讲或以谁的名义发、多长或讲几分钟、哪个学段。
- 写评语：请准备学生事实表，每人两三件具体表现和一条需要改进的地方。姓名请用编号（S01、S02）或座号代替。
- 可选：单位画像 `.gongwen/单位画像.md`、领导偏好卡。没有也能用。

## 输出

在 Claude Code、Codex、Cursor 等能写文件的工具里，输出到 `公文/<日期>-<标题>/`：

| 文件 | 内容 |
|---|---|
| `正文.txt` | 只含正文的纯文本，可直接粘进 Word 或交给 gongwen-format 排版；评语为“编号：评语”每人一段 |
| `素材台账.md` 或 `评语事实表.md` | 每条事实的内容和来源 |

起草说明只在对话中给出，不超过 5 行，不另存文件。在网页大模型里使用提示词版时，依次输出正文、起草说明和台账。

## 本地脱敏和检查脚本

`scripts/k12_check.py` 在本机运行，不联网。读取文本、Markdown、CSV 只需 Python 标准库。读取 `.docx` 需要 `python-docx`，读取 `.xlsx` 需要 `openpyxl`。

| 命令 | 作用 |
|---|---|
| `python scripts/k12_check.py mask 学生情况.xlsx --drop-sensitive` | 在本机把姓名换成 S01 等编号，删去身份证号、手机号、学号、住址，涉及家庭、健康、处分信息的句子换成【已略去】，另存脱敏稿和对照表。对照表只留在本机 |
| `python scripts/k12_check.py unmask 评语.txt 学生情况-对照表.csv` | 评语写好后，在本机把编号换回姓名 |
| `python scripts/k12_check.py comments 评语.txt --facts 学生情况-脱敏.md` | 查评语用语、考试排名和分数、家庭健康处分信息、雷同套句、篇幅和人称，提供事实表时对账。17 条 PY 规则 |
| `python scripts/k12_check.py parents 家长信.txt` | 查面向家长的材料：家长作业与打卡、考试成绩、作业量、收费与依据、课后服务、校外补课与学生信息导流、升学承诺、点名批评和转发等。14 条 JZ 规则，也检查表格姓名 |
| `python scripts/k12_check.py general 学期总结.txt` | 查校内综合文书：考试成绩排名、补造记录、课后服务、学生敏感身份与实名、强制收费或购买、收费缺依据、校外补课与学生信息导流。7 条 K12-G 规则 |
| `python scripts/k12_check.py --list-rules` | 列出 `comments`、`parents`、`general` 全部 38 条专检规则、学段级别集合、触发条件与 `skip` 项 |
| `python scripts/k12_check.py --list-rules --json` | 以 JSON 格式输出全部 38 条专检规则的元数据 |

三个检查入口默认按义务教育检查，含小学和初中。高中、中职材料加 `--stage 高中` 或 `--stage 中职`。机检 P0 优先复核，人工确认后必改。P1 需结合原文核对，P2 是一般提示，`skip` 表示该学段跳过该规则。脚本生成的文件同名时自动加 -v2。

**姓名识别与遮蔽**。`general` 和 `parents` 将识别到的学生姓名登记进全文姓名表，文本与 JSON 摘录、文件名统一替换成〔姓名1〕等。并列链有一项识别成功时，也登记符合形态的其他姓名。正文中的 `K12-G04` 由 `general` 报出。敏感身份用固定清单，包括困难家庭、残疾、受助、留守、处分、患病等。姓名和身份需有明确关系，例如“低保家庭学生＋姓名”“特困学生：＋姓名名单”或“姓名＋同学＋归属谓词＋身份”。本人身份清楚且姓名证据充分时可报 P0，名单继承、低置信或关系存疑可报 P1，原有命中保留。两入口都检查表格姓名列。Markdown、CSV、XLSX 沿用原有分级，Word 新接入的表格姓名提示为 P1。应查姓名列有未识别内容时可报 P1。姓名识别依赖 `gw_names.py` 和 `gw_names.json`，缺失或损坏时脚本报错。

**收费、补课、排名与收费依据**。

- `JZ-006`／`K12-G05` 按分句和收费项目核对。明确的校方强制缴购或统一代办，满足分句条件时按义务教育 P0、高中与中职 P1 提示。拒缴后果、家委会实收或议事、自愿与强制同时出现、证据不全等可能报 P1。明确自愿且同项可退出、无强制动作或拒缴后果的代办可跳过，仍须核对实际做法。依据见 S04、S07、S15、S18。
- `JZ-008`／`K12-G09` 按分句查学校组织或推荐学生参加校外有偿补课，或向校外培训机构介绍生源、提供学生和家长信息。各学段明确命中可报 P0，学校施事、有偿、校外或信息去向待核时可报 P1。明确禁止、教师本人受训或免费且无导流可跳过新增判定。依据见 S22。
- `JZ-003`／`K12-G01` 保留原有排名命中，义务教育可报 P0，高中、中职报 P1。各入口检查对象有别，家长入口还单查分数 `JZ-014`。
- `K12-G06` 只在 `general` 报 P1。正文按自然段、Markdown 和 Word 收费表按行，核对正向收费或明确标准中的金额是否有适用依据。可识别合适的收费文件、文号、外部批准标准和明确的收费依据占位；统计、纯免收或退费另行判断。家长入口 `JZ-007` 仍只查正文行。人工查全文和附件，确认无依据时按审稿红线处理。
- Word 表格参与收费、补课、排名、姓名遮蔽与收费依据检查。督导达标断言、安全教育记录实到人数与佐证、非教学任务摊派与白名单外进校园见 [人工核稿清单](references/review-addon.md)。

**评语编号净化**。`comments` 使用既有姓名遮蔽，保留 S01 等本机定位码。编号列或明确标签可登记学号、考号、长证件号、手机号等。带标签的编号从连接符后取值，遇到汉字、句读、成对标点、竖线、破折号、省略号或行尾结束。`和、与、及` 两侧都是字母数字记号时仍算同一段。区间内的数字一并遮蔽，小数与点分号按整串处理。含数字的已确认编号达到 5 个字符时可在全文遮蔽，正文和文件名中的紧凑复写也可遮蔽。希望保留的数量可用逗号隔开或放在汉字后。已识别的编号不参加 `PY-016` 数字对账。

## 注意事项

1. **保密**：涉密材料请勿输入联网 AI。材料里有学生个人信息、“内部”“不公开”字样等敏感信号时，会在起草说明末尾提示一句；标有“内部资料”“不得外传”的材料会先停下来。学生姓名、学号、家长电话、家庭情况、心理健康等信息，请先脱敏。
2. **不编造**：学生表现、活动次数、参与人数、获奖、放假时间、收费标准、自评等级只用你提供的。缺了就写不成的才标【待补】（一篇一般不超过 3 处），存疑的不写进正文，只在起草说明里请你核实。你只说“下周四”的，稿子里按今天推算为具体日期，起草说明注明推算依据；材料里加引号的本校提法原样保留。
3. **篇幅不注水**：你给了字数或讲话时长，按 ±10% 写；素材撑不起时，用工作性表述补足常规板块，不新增事实，起草说明说明哪几部分是常规表述，不拿套话凑字数。
4. **只整理，不补造**：没开展过的班会、教研、家访，不会替你补记录；综合素质评价的写实记录要由学生本人填写，这里只给填写指引。
5. **政策以原文为准**：双减、考试管理、安全管理等要求标了文件和条款（见 `references/sources.md`），各地规定更细的，以你提供的本地文件为准。
6. **事实和判断由你负责**：它负责搭结构、守规矩、查错漏，材料是否报送、怎么定调由你和学校决定。

## 已知局限

- **本地政策与人工核查**。制度依据于 2026-10-16 在线核实。地方督导、课后服务和收费要求以当地文件为准。脚本按现有措辞和结构检查，收费文件的真伪、效力和文中未写明的适用范围由人工核对。起草说明请用有标识的标题，如“【起草说明】”。单独一行只写“起草说明”可能继续按正文检查。
- **收费、补课和排名**。校园意外险等简称、缺少强制信号的扫码支付或补交、口语拒缴和未收录后果（如欠缴、停发作业本）可能漏报。“未报名学生须缴纳研学费”少了“的”时也可能漏报。明确收费紧接“免费发放”时，前项收费可能被压制。复合或按期计费（如每生每月、按学期）在强制收费规则中可能漏报。衔接班、强化班、特训班或共享花名册等写法可能漏报。教师受训的修饰语或地点超出支持范围时，可能保留原 P0 或报 P1。转告补习禁令后有收尾分句、含部分条文引语或用“不许”约束普通动作时可能报 P1。无发布动词的“全班第一名”“倒数第三名”沿用家长入口检查。“不晒成绩”“学校不按成绩排名”等直接否定也可能保留原命中。排名反转句尾用“吗！”或“呢！”，以及部分反转句尾用“吧。”或“呀。”时，义务教育仍可能报 P0。
- **收费金额与依据**。同句多项目、指代不明、前句仅否定提及某项目或用分号串写多项时，项目和依据可能错配。无收费动词的冒号单价、金额与动作分开写（如“每套45元，由班主任代收”）可能漏报。仅列单价时，跨句依据须由下一句独立说明该项目。金额可用复合计价单位，依据可带括注文号。家长入口的 `JZ-007` 不读 Word 表格，正文同行有“根据”“按照”“依据”等提示词可放行，统计性“根据”也可能放行。
- **收费表头与定位**。Markdown 与 Word 收费表逐行检查正金额。明确项目列支持“收费项目、收费项目名称、费用名称、费用项目、收费名称、收费科目、收费明细、缴费项目、缴费明细、缴费名称、代收项目、代收名称”。可配“金额、费用、单价、标准、费用标准”等列，也可配“收费金额、缴费标准、代收金额”等明确列。泛称“项目、名称、类别”须配明确金额列。列头可带空白和“（元）”“（元/人）”等单位。组合如“项目｜金额”“项目名称｜收费标准”“服务项目｜收费金额”“事项｜收费金额”“代收费项目｜金额”可能漏报，“金额（单位：元）”“180（每学期）”“每生120”也可能漏报。“代收项目”下的校服补订等项目可能与同一行依据错配。无表头且后项项目名不明确时，收费或退出条件可能归错项。Word 同一表格的行号因规则按插入位置或正文段数定位而可能不同。CSV、XLSX 沿用各自的导入及姓名列逻辑。Python 3.9 读取含 NUL 字符的畸形 CSV 时，家长和综合文书入口可能报错。
- **分句和作用范围**。无序号冒号禁令只管紧接的首个非列表独立段，空行或第二段后恢复普通判断。标题后独立段、无冒号的前段、跨完整句号的后置辟谣也按现有句界判断。合规禁令、转述、治理、待议场景仍可能报 P1。连续句末标点中有问号时，位于同一行的空白、格式控制符、非间距标记及控制字符不会改变疑问判定。
- **敏感身份和姓名**。以清楚陈述的学生本人身份为主。亲属身份、跨段回指、跨逗号的“该生本人系……”、名单用特殊修饰、病名后接不常见词等可能报 P1 或漏报。合规禁令、疑问和假设含实名时也可能报 P1，原有帮扶命中保留。“留守学生某生由祖母照管”“某同学被记过后情绪低落”“另有残疾学生某生”“受助学生某生本学期新增纳入名单”“患有焦虑症的学生某生”均有漏报样本。姓名未登记时，后文的成绩通报、倒签记录等其他规则的摘录里可能原样出现。“王同学”这类已脱敏称呼后若紧接括注、顿号或连词，也可能被当作真实姓名。发送文本或 JSON 报告前请通读并遮蔽，单独核对文件名。
- **表格和姓名写法**。姓名列依赖可识别表头。Markdown 表格通常报 P1，姓名证据及同表敏感列充分时可报 P0。公开署名和普通分工表通常跳过，有敏感列时仍检查。“名字”作为 Word 表头可能漏识。应查姓名格有未识别内容时可报 P1。括号、嵌套标记和并列姓名可按可见文字检查。HTML 姓名紧邻纯文本姓名、性别或科室时可能只给兜底 P1，二字姓名夹实体或注释时可能拆开漏登。少见姓氏、复姓后接“测试”、与普通词同形的姓名、名单过于零散、只有文件名出现或并列各项都无证据，也可能漏登。带“·”的姓名、外文名、昵称及家长姓名须人工核对。姓名残段、单位或职务可能被一起遮住，重叠片段有时留下姓名尾字。含学生姓名的评语文件名可能原样显示。
- **评语编号**。全角数字、未约定标签或等号分隔的短号、与 S 定位码相似的真编号、仅在文件名里的手机号、拆列后连写的超短号、正文独立出现或重复的 5 字符以下短号可能回显。无明确分段的空格串按一个编号处理，普通数量与已确认长号相同时会一并遮蔽。请使用编号列或明确标签，传出前复查正文、报告和文件名。
- **其他漏报写法**。课后服务的“必须参加”离项目名较远、先写“总分前十”再写张贴、点名与批评距离较长、迎检补写与“家访记录”距离过长时，都有漏报样本。评语中“数学卷面98分”“保证你能进重点高中”也请人工核对。
