# 中小学行业包（gongwen-k12）

> 版本 1.1.0　成熟度：Stable（稳定版）

给中小学校长、中层干部、班主任和任课教师用的写作助手，专写学校里特有的材料：学期计划总结、督导自评、班主任计划总结、家长会讲话、学生评语、安全教育记录、致家长的一封信、教研活动记录、课后服务方案。

它先把你给的材料整理成台账或事实表，再搭结构，第一轮就交完整的稿子。必须由你提供的数据缺了标【待补】，不替你编；要问的问题（最多 3 个）放在回复末尾，不耽误出稿。学校材料的几条线它会替你守住：学生信息不外露，考试成绩不排名，不给家长布置作业，没开展过的活动不补记录。

## 能做什么

| 文书 | 说明 |
|---|---|
| 学期工作计划和总结 | 学校、处室、年级组、教研组；按德育、教学、教师队伍、安全、家校协同组织，计划带行事历 |
| 督导评估自评报告 | 按督导指标逐项写达成情况和佐证材料，附佐证材料清单；自评等级由学校定。县级教育部门的县域优质均衡自评也能写 |
| 班主任工作计划和总结 | 具体到本班；个别学生只写在校表现和教育措施 |
| 家长会讲话稿 | 按讲话时长控制字数（约每分钟200字），口语化；不点名、不公布成绩 |
| 学生评语 | 期末评语、综合素质评价教师评语；每人按事实写，查雷同；用编号代替姓名 |
| 安全教育记录 | 安全班会、安全教育课、疏散演练；只整理已开展的活动 |
| 致家长的一封信 | 寒暑假、开学、专项安全提醒、课后服务告知；可加家长群短信版 |
| 教研活动记录 | 集体备课、听课评课、主题研讨；发言归属准确 |
| 课后服务方案 | 自愿参加、作业辅导和素质拓展、考勤交接、经费依据 |

## 你可以这样说

1. “期末了，帮我给班上42个孩子写评语，每个孩子的情况我列在表里了。”
2. “下周三开家长会，我是初一班主任，要讲10分钟左右，帮我弄个发言稿。”
3. “市里要来做办学水平督导，这是评估细则和各处室交上来的材料，帮我写个自评报告。”
4. “寒假快到了，以学校名义给家长写封信，提醒一下安全。”
5. “这是上周英语组听课评课的笔记，帮我整理成教研活动记录。”

## 输入

- 必需：你手头的素材。工作记录、处室报上来的情况、学生情况表、录音转写、上级通知都可以，不用先整理。
- 最好说明：写给谁、谁来讲或以谁的名义发、多长或讲几分钟、哪个学段。
- 写评语：请准备学生事实表，每人两三件具体表现和一条需要改进的地方。姓名请用编号（S01、S02）或座号代替。
- 可选：单位画像 `.gongwen/单位画像.md`、领导偏好卡。没有也能用。

## 输出

在 Claude Code、Codex、Cursor 等能写文件的工具里，输出到 `公文/<日期>-<标题>/`：

| 文件 | 内容 |
|---|---|
| `正文.txt` | 只含正文的纯文本，可直接粘进 Word 或交给 gongwen-format 排版；评语为“编号：评语”每人一段 |
| `素材台账.md` 或 `评语事实表.md` | 每条事实的内容和来源 |

起草说明只在对话中给出，不超过 5 行，不另存文件。在网页大模型里使用提示词版时，依次输出正文、起草说明和台账。

## 本地脱敏和检查脚本

`scripts/k12_check.py` 只用 Python 标准库，不联网（读 .docx 需要 python-docx，读 .xlsx 需要 openpyxl）：

| 命令 | 作用 |
|---|---|
| `python scripts/k12_check.py mask 学生情况.xlsx --drop-sensitive` | 在本机把姓名换成 S01 等编号，删去身份证号、手机号、学号、住址，涉及家庭、健康、处分信息的句子换成【已略去】，另存脱敏稿和对照表。对照表只留在本机 |
| `python scripts/k12_check.py unmask 评语.txt 学生情况-对照表.csv` | 评语写好后，在本机把编号换回姓名 |
| `python scripts/k12_check.py comments 评语.txt --facts 学生情况-脱敏.md` | 查评语：贬损和标签用语、考试排名和分数、家庭健康处分信息、雷同和套句、篇幅、人称，并与事实表对账 |
| `python scripts/k12_check.py parents 家长信.txt` | 查面向家长的材料：要求家长检查批改作业、给家长布置作业、公布成绩分数和排名、收费和统一购买、推荐校外培训、强制参加课后服务、承诺升学、点名批评 |
| `python scripts/k12_check.py general 学期总结.txt` | 查校内综合文书（学期计划总结、督导自评、课后服务方案、安全教育和教研记录）：公布考试成绩排名、补造台账记录、课后服务讲新课或强制参加、学生隐私外露（K12-G04）、强制收费与统一购买（K12-G05）、收费缺依据（K12-G06）、校外有偿补课与推荐校外培训（K12-G09） |
| `python scripts/k12_check.py --list-rules` | 列出 `comments`、`parents`、`general` 全部 38 条专检规则、学段级别集合、触发条件与 `skip` 项 |
| `python scripts/k12_check.py --list-rules --json` | 以 JSON 格式输出全部 38 条专检规则的元数据 |

高中、中职材料加 `--stage 高中` 或 `--stage 中职`。脚本输出的文件已存在时自动加 -v2，不覆盖。

**姓名识别与遮蔽**：`general`、`parents` 报出的原文摘录里，识别出的学生姓名会换成〔姓名1〕〔姓名2〕，屏幕和 `--json` 输出都一样，同一姓名在后文单独出现也会遮住；“、”并列的后项（“周梓涵、吴雨桐等5人”）即使自身分数不足也会登记并遮蔽，宁可多遮。`comments` 的“编号”列（label）是你在本机定位评语用的标识，通常保留。Markdown 表格的姓名列登记了实名时，评语定位标签、文件名和全部输出也遮蔽这些姓名。学生隐私（K12-G04）按“敏感身份词加姓名”识别：“低保户张明同学”“特困学生名单：郑磊、孙婷”报 P0，把握不大的报 P1；“特困学生：一年级、三年级各2人”这类汇总人数的写法、没有冒号的“名单已报送”不报。这套识别依赖 `scripts/gw_names.py` 和 `scripts/gw_names.json`，缺少或损坏时所有子命令（包括 `mask`、`unmask`）都会报错退出，不会悄悄跳过。

**校内综合文书新增规则与学段口径（`general`）**：
- `K12-G05`（强制收费、统一购买与家委会违规收费，与 `parents` 的 `JZ-006` 共用项目级判定）：义务教育报 P0，高中与中职报 P1；同一收费项目内既写明自愿、又写明可以不参加（如“不参加不收费”“可自行购买”“不强制”）且无同项强制动作或不缴后果的代办不报（人工仍须核对是否真自愿）；同一项目里仍有强制动作或不缴后果（如不缴不发教材、不予报名）的，按强制处理（义务教育 P0、高中与中职 P1）；只写“自愿统一购买”而无“可不参加”说法的报 P1；引述禁止不报；同句不同项目分开判定。依据对应《中小学教辅材料管理办法》（S07）、《中小学幼儿园安全管理办法》第四十六条（S18）、《关于健全学校家庭社会协同育人机制的意见》（S15）和“双减”意见第 9、20 段（S04）。
- `K12-G06`（收费缺依据）：按真实段落（空行切分）或表格行核查，有具体金额与收费执行动词但同段/同行缺少可信政策依据（书名号文件、文号、批准标准等，区分并排除“根据报名人数统计”这类统计性“根据”）时报 P1（提示核查全文及附件；人工确认全文确无依据的升为 P0），排除统计、免收、财政预算拨付与 `【待补】` 占位。已知局限：`parents` 入口的 `JZ-007` 仅看同一行，且同行见“根据”“按照”“依据”等关键词即放行（如“根据报名人数统计”同行的收费句不报），差异留待后续统一。
- `K12-G09`（校外有偿补课与推荐校外培训，与 `parents` 的 `JZ-008` 共用判定）：各学段均报 P0，依据《严禁中小学校和在职中小学教师有偿补课的规定》（S22），仅针对学校或教师明确组织、推荐学生参加校外有偿补课，或向校外培训机构介绍生源、提供学生信息；教师培训、校内合规辅导和禁止性引述不报；含糊的非学科或免费活动留人工核查。
- 督导自评达标断言、安全教育记录实到人数与佐证、非教育教学任务摊派与白名单外进校园三项本轮不写入机检，在 `references/review-addon.md` 标为人工核查。

**学生隐私（`K12-G04`）三个入口与新增词局限**：
- 覆盖三个入口：`general` 报出 `K12-G04`，`parents` 与 `comments` 的摘录遮蔽同步调用同一套学生隐私姓名识别。
- 新增敏感身份词（残疾/残障、受助/资助对象/助学金受助、留守学生、患病/患有某病/确诊/焦虑症/孤独症/随班就读/特殊教育、被记过/被警告/被留校察看/被处分、单亲/离异/事实无人抚养/贫困户/贫困家庭；依据《未成年人保护法》第四条 S21）走独立明确关系锚点，仅在“身份词＋学生/同学/儿童/子女或冒号名单”或“某生（姓名＋同学/学生）＋属于/系/为/患有/确诊/被记过/被处分/享受等归属谓词＋身份词”时启用，不对新词启用“同分句出现即判”的后锚点；人数汇总、职务、项目名、教研活动名不报。
- 弱锚点局限：未形成上述任一关系锚点（既非冒号名单、又缺少学生称谓或明确归属谓词，如仅写某人自身患病需长期随访）仍可能漏报，对外或发给外部工具前仍须人工通读复核。

## 注意事项

1. **保密**：涉密材料请勿输入联网 AI。材料里有学生个人信息、“内部”“不公开”字样等敏感信号时，会在起草说明末尾提示一句；标有“内部资料”“不得外传”的材料会先停下来。学生姓名、学号、家长电话、家庭情况、心理健康等信息，请先脱敏。
2. **不编造**：学生表现、活动次数、参与人数、获奖、放假时间、收费标准、自评等级只用你提供的。缺了就写不成的才标【待补】（一篇一般不超过 3 处），存疑的不写进正文，只在起草说明里请你核实。你只说“下周四”的，稿子里按今天推算为具体日期，起草说明注明推算依据；材料里加引号的本校提法原样保留。
3. **篇幅不注水**：你给了字数或讲话时长，按 ±10% 写；素材撑不起时，用工作性表述补足常规板块，不新增事实，起草说明说明哪几部分是常规表述，不拿套话凑字数。
4. **只整理，不补造**：没开展过的班会、教研、家访，不会替你补记录；综合素质评价的写实记录要由学生本人填写，这里只给填写指引。
5. **政策以原文为准**：双减、考试管理、安全管理等要求标了文件和条款（见 `references/sources.md`），各地规定更细的，以你提供的本地文件为准。
6. **事实和判断由你负责**：它负责搭结构、守规矩、查错漏，材料是否报送、怎么定调由你和学校决定。

## 成熟度

Stable。9 类文书的模板、十条行业红线和本地脱敏检查脚本已可用，脚本配有单元测试（`tests/k12/`，含必错和必过标本）；评测用例见 `evals/`。v1.0 真实模型评测（Sonnet 5.5，17 条用例）中，A 组（装 skill）期望通过率 98.4%（124/126）。v1.1 抽样评测（2026-11-04，A 组 7 例）期望通过率 80.9%（38/47），经复核编造 0 次；触发评测正例 10/10、反例 10/10（沿用 v1.0，本轮 description 与 trigger.json 未改）。通过率接近 80% 的门槛，已知失误是审稿清单照抄学生姓名（违反红线一），属模型执行偏差，规则已在。按 CONTRIBUTING 的 Stable 标准评定，一线测试反馈在升级后持续收集，确认出现严重问题（编造、红线错误）时降回 Beta。评测记录见仓库根目录 evals/results/v1.1-industry-sample.md，v1.0 记录见仓库根目录 evals/results/v1.0-benchmark.md。已知局限：

- 制度依据于 2026-10-16 在线核实，地方规定差异大，督导指标、课后服务时间和收费以当地文件为准；
- 脱敏脚本识别不了家长姓名、单字名的昵称，交给 AI 前请再看一遍脱敏稿；
- 学生隐私检查靠敏感身份词当锚点，**敏感身份词是固定清单**：新增敏感身份词（残疾、受助、留守学生、被记过/被处分、患病等）仅在明确关系锚点（见上文 `K12-G04` 的“身份词＋学生/同学/儿童/子女”“身份词＋冒号名单”“某生＋归属谓词＋身份词”三类入口）下识别，未形成上述任一关系锚点，或身份词不在清单内的写法（如“学生 + 姓名 + 的 + 亲属 + 敏感事件”），不当锚点、可能漏报；没有“低保”“建档立卡”等词、孤零零出现在正文的姓名识别不了；带姓名列的 Markdown 表格默认报 P1，有困难类型、病史等敏感列时报 P0，公开署名及无个人敏感列的整改分工跳过，分工表另列病史时照报责任人。应检查的姓名格含未识别残段时，即使同格已有姓名，该行也报一条 P1“姓名列内容未能识别，请人工核对”。括号内外均检查。姓名中间的嵌套 Markdown 和 HTML 标记按可见文字识别。相邻元素拼接后无法识别、各元素单看均为姓名时，逐人报出。两个字以上的汉字残段整段遮蔽，段内每一处以表内姓氏开头的两、三字片段也登记，长名优先。单位、部门或职务用语可能随之被遮蔽。若摘录从两个等长且重叠的片段中间开始，左侧片段可能先匹配，使右侧姓名留下尾字。少见姓氏未入姓氏表时，夹在修饰语中的姓名在别处仍可能露出。无姓名类表头或非 Markdown 表格的姓名仍可能漏报；并列链（“、”或“和、与、及、同、跟”连接）里只要有一项被识别，其余姓氏开头的 2～4 字项（含与常用词同形的）一律登记并遮蔽，整条链上没有任何一项被识别时不登记，只有同一姓名在别处被锚点识别过，才能在摘录里遮住；身份词与姓名之间隔着其他成分（“低保家庭的三年级学生周梓涵”）识别不了；与常用词同形的姓名（刘海、林海、黎明、高峰）只在有强证据（如姓名后紧跟“同学”）时识别，其余漏报；名字里含“会”“山”等字的、两字少见姓和歧义姓的姓名、名字用字不在常见名用字表里的姓名，在生僻后续下会漏报；摘录遮蔽是整串替换，可能多遮；带“·”的姓名、外文名、昵称识别不了；旧入口的“受到处分的学生”写法只覆盖“受到（警告、记过等）处分的学生/同学”后直接接姓名的情形，“该生因打架受到处分”不报（新增的“被记过/被警告/被留校察看/被处分”须走上文明确关系锚点）；报告里的文件名会遮蔽正文已识别出的姓名（“马小明家访记录.txt”显示为“〔姓名1〕家访记录.txt”），文件名里有、正文没识别到的姓名遮不住，发给别人前请自行改名；
- 行业内容欢迎一线教师、校长贡献模板和术语。
