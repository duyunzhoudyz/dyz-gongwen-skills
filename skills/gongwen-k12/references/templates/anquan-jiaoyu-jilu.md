# 安全教育记录

## 一、用途和边界

记录已经开展的安全教育活动：安全主题班会、安全教育课、专题讲座、应急疏散演练，以及开学初、放假前的集中安全教育。学校应当建立安全工作档案（《中小学幼儿园安全管理办法》第二十七条，`references/sources.md` S18），安全教育记录是其中一部分。同一办法还规定：安全教育纳入教学内容（第三十八条）；开学初、放假前有针对性地集中开展安全教育（第三十九条）；每学期至少开展一次针对洪水、地震、火灾等灾害事故的紧急疏散演练（第四十二条）。

借用流程：按 gongwen-minutes 的做法整理，只整理，不添加。

不归本模板：演练方案、安全工作方案交 gongwen-report；安全事件情况报告交 gongwen-draft；给家长的安全提醒用 `references/templates/zhi-jiazhang-xin.md`。

## 二、开工前优先问的三件事

1. 活动类型、时间、地点、组织者或主讲人。
2. 参加对象和人数。
3. 原始材料：笔记、课件、签到表；学校有固定记录表的，请提供栏目。

## 三、记录格式

下面的格式示例中，时间、班级、主题都是示意，实际一律照用户材料填写；材料没有的，时间、地点、实到人数标【待补】，其余不推测。

```text
安全教育记录
时间：2026年5月11日（星期一）下午第二节
地点：五（4）班教室
主题：防震避险
主讲：班主任
参加对象：五（4）班学生，实到【待补：人数】人
形式：安全教育课
主要内容：
1. ……
2. ……
活动过程：……
效果和后续安排：……
记录人：……
```

应急疏散演练记录另加：演练科目；参演人数；从发出警报到全部到达安全区域的用时；发现的问题和改进措施。数据只用用户提供的。

## 四、结构要点（按活动类型）

先判断材料属于哪一类，再取对应的栏目。材料里没有的栏目写“本次未涉及”或标【待补】，不凑栏目。

| 活动类型 | 主体栏目 | 容易漏的 |
|---|---|---|
| 主题班会、安全教育课 | 主题；主讲；对象和实到人数；形式；讲了哪几条具体做法；互动或演示；当场发现并纠正的问题；后续 | 实到人数；讲的是“做法”还是“口号” |
| 专题讲座 | 主讲人（外请的写单位和身份，用户提供）；内容要点；提问和回应；后续 | 外请人员的来源和身份只用用户材料 |
| 应急疏散演练 | 演练科目；模拟情景；组织分工；参演人数；疏散路线；用时；发现的问题和改进措施 | 用时和人数的统计口径；问题与改进要一一对应 |
| 开学初、放假前集中教育 | 集中教育的场次和对象；覆盖的主题（只写材料中讲过的）；形式；未到人员的补课安排 | 覆盖的主题以实际讲过的为准，不照常规清单全列 |

几条通用要点：

1. 一次活动一份记录，标题写明活动类型和主题。
2. 主要内容写成“怎么做”的条目，而不是“要重视”的态度。
3. 活动中发现的问题（学生做错的动作、路线拥堵的位置）如实记，并写当场怎么处理。
4. 后续安排写清谁、何时、做什么，只写材料中有的。

## 五、只整理，不补造

1. 记录只来自已经开展的活动。时间、地点、组织者、参加对象和人数、内容、过程、效果，都要有用户提供的依据：笔记、签到表、课件、照片说明。
2. 用户要求“补”没有开展过的活动记录的，不写（`references/redlines.md` 第八条）。用一句话说明原因：补造的记录是虚假台账，迎检时也经不起核对。然后提供本学期剩余周次的安全教育安排表和空白记录模板，活动开展后再记录。
3. 活动开展了、细节记不全的，缺的写【待补：说明】，不推测“学生积极参与，效果良好”。
4. 材料写“几个”“一些”的，照写“几名”“部分”，不换成具体人数；年份没写的，起草说明写明按哪一年记，请用户核实。

## 六、写法

1. 时间写全：年、月、日、星期、节次，与校历核对。用户只说“上周三”“昨天”的，按今天推算为具体日期。
2. 内容写具体讲了什么。例如防溺水教育讲“六不”（来源见 S20，以当年原文为准）。
3. 效果写看得到的结果，不写评价套话（见第七部分第 1 条）。
4. 不写学生姓名；需要记录个别情况的，用“某同学”。
5. 记录人写实际记录的人。
6. 一次活动一般300～600字；用户学校有固定表格的，按表格栏目填。

## 七、常见错误与正误对照

下面各条“正”只示意写法，其中的做法和细节以用户材料为准，不得搬进正文。

1. 效果栏写评价套话：“安全意识得到极大提高”，没有一件看得到的事。
   - 误：通过本次活动，同学们的安全意识得到了极大提高，取得了良好的效果。
   - 正（笔记：请几个学生演示“伏地、遮挡、手抓牢”，有学生躲到了窗边，当场纠正）：活动最后请几名学生上台演示“伏地、遮挡、手抓牢”，有学生躲到了窗边，当场纠正。
2. 内容栏只有“学习了安全知识”，没有讲了哪几条做法。
   - 误：主要内容：学习了防溺水知识，增强了自我保护意识。
   - 正（笔记：讲了“六不”，强调不独自去河边）：主要内容：讲解防溺水“六不”，强调不私自下水、不擅自与他人结伴游泳。
3. 人数、时间不全：实到人数空着，只写“全班”；日期只写“上周”。
   - 误：参加对象：全班学生，到齐。
   - 正：参加对象：某班学生，实到【待补：人数】人。（签到表在别处的，请用户补报）
4. 把一次活动写成两次，或把两次合成一次，与签到表、课表对不上。
5. 演练记录没有用时，或只写“顺利完成”，没写发现的问题。
   - 误：演练组织有序，全体师生安全撤离，演练取得圆满成功。
   - 正（笔记：警报后学生到操场集合，二楼楼梯口有拥堵，老师当场疏导）：警报响起后，各班依次到操场集合，二楼楼梯口出现拥堵，值班教师现场疏导。用时【待补：全部到达操场的用时】。改进措施【待补：学校确定的改进措施】。（用时、改进措施笔记没有的，不编）
6. 写进学生姓名或个别学生的家庭情况。
   - 误：张明同学又一次没认真听，被老师批评。
   - 正：活动中有一名同学演示动作不规范，老师当场示范纠正。
7. 补造没有开展的活动（见第五部分）。
8. 事后加入没有的内容：笔记里没有的互动、提问和学生反应。

## 八、全年常见节点

以当年上级通知和校历为准。

| 时间 | 节点 |
|---|---|
| 开学初、放假前 | 集中安全教育（S18 第三十九条） |
| 3月最后一周的星期一 | 全国中小学生安全教育日（1996年起，2026年为3月30日，S19） |
| 4月15日 | 全民国家安全教育日（《国家安全法》第十四条，S25），是否安排主题教育以学校计划为准 |
| 5月12日前后 | 全国防灾减灾日（2009年起，S26），常组织疏散演练 |
| 5月至9月 | 防溺水教育 |
| 11月9日前后 | 全国消防日，常组织消防演练 |
| 每学期 | 至少一次紧急疏散演练（S18 第四十二条） |

## 九、数据项（用户提供才写）

时间（年、月、日、星期、节次）；参加对象和实到人数；活动时长；演练的参演人数和疏散用时；发现的问题条数。笔记里没有的不推测，缺了记录不成立的标【待补】，签到表在别处的，请用户补报人数。
