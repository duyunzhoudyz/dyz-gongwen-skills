# 中小学写作日历

> 核验日期：2026-11-04

按月列出学校的写作高峰和对应 skill。时间是常见惯例，具体以当年教育局校历、上级通知和本校安排为准；提示用户时用“一般”“通常”。共享的通用日历见总入口 gongwen。第三部分的节点和考试安排于 2026-11-04 联网核实，出处见 `references/sources.md` S24～S31；第一、二部分是常见惯例。

| 9月第三周 | 国家通用语言文字推广普及宣传周（2026年为9月14日至20日） | 推普周活动方案和新闻稿；致家长的一封信 | gongwen-implement、gongwen-brief、gongwen-k12 | S24 |
| 秋季开学后 | 教育事业统计年度填报：教育部每年发文部署，学校按县、市教育部门的布置填报 | 填报数据的核对表；学校基本情况（督导自评、学期总结共用口径） | gongwen-data、gongwen-k12 | S30；时点和截止日以当年通知为准 |
| 每学年，上报时间按年度通知 | 国家学生体质健康标准测试：学校对全体学生每学年测一次，数据经当地教育部门审核后上报；学校在校内公布总体结果，中小学向家长通报 | 学期总结中的体质健康板块；致家长的信；数据统计交 gongwen-data | gongwen-k12、gongwen-data | S29；上报截止日以当年通知为准 |
| 11月前后 | 教师资格考试面试报名（2026年自11月6日起） | 同上 | gongwen-draft | S28 |
| 12月4日 | 国家宪法日（宪法宣传周常在12月上旬） | 法治教育主题班会记录 | gongwen-k12 | S27 |
| 每年，时间由省市通知 | 中小学教师职称评审 | 教师个人材料，本包不写；个人总结交 gongwen-report | gongwen-report | 时间以省级人社、教育部门通知为准 |

几条提示规则：

1. 一次最多提示三条，优先提示时间最近且本包能写的。
2. 教师资格考试、职称评审是教师个人事务，学校层面最多写提醒通知，个人申报材料不代写。
3. 教育事业统计和体质健康数据都是“数”的工作：填报口径先于文字，数据核对、率的计算交 gongwen-data，学期总结和督导自评引用同一口径。
4. 考试成绩、体质健康结果只写整体情况，不排名、不公布个人（`references/redlines.md` 第二条）。
