口径见 [中小学引擎包判定口径](../../../../docs/中小学引擎包判定口径-2026-11-25.md)。第 0 步的数据供实施和独立评审使用。

## 文件与计数

| 文件 | 内容 |
| --- | --- |
| `probes.jsonl` | 五轮主清单。R1～R5 分别 107、64、55、48、45 条源记录，共 319 条，去重后 318 条。 |
| `supplemental_text.jsonl` | 376 条补充正文，来自报告附录、方案走查和旧版写者夹具。 |
| `output_probes.jsonl` | 67 条评语 CLI 和工具箱 HTTP 探针，保留事实表、文件名或请求差异。 |
| `baseline_false_positives.jsonl` | 集成基线实测 P0 的合规行为，含 K1 应留及点名豁免。含同一句有独立真违规、但其中一个规则命中是误报的情形。 |

共 761 条独立输入，保留 1,292 次来源登记。旧版 `policy_review_cases.jsonl` 的 635 条与 `baseline_eea1232.jsonl` 的 1,270 个历史入口结果附在对应来源。正文同原文和原学段合并，入口在一条内展开。HTTP、CLI 文件名或事实表会影响结果，单独记为对应输入。补充正文的原始文种按存档取值，无显式文种时用文本／Markdown 自动判别。

## 记录字段

| 字段 | 用法 |
| --- | --- |
| `schema_version` | 记录格式版本。 |
| `id`、`text`、`stage`、`entries` | 稳定主键、逐字原文、源学段及入口。源 ID 见 `sources`，可按原编号查找。|
| `category`、`basis`、`decision` | 主类别、口径条目、该类别的行为判定或作用域。 |
| `sources` | 源组、源文件、源 ID、原学段及原期望。轮次探针有 `round`。旧写者结果含 `frozen_eea1232`，这是历史快照。 |
| `sources[].comparison` | 对比原期望与最终级别。含冲突、集合收窄、集合变更或输出契约差异。`different:null` 表示原材料没有给出可比的逐规则预期。历史命中下限被具体化也记作收窄。 |
| `by_stage.<学段>.expected` | 按入口和规则存允许级别集合。`["SKIP"]` 要求该规则无命中，`["SKIP","P1"]` 允许两种状态。空对象表示该入口无目标命中。`expected_new_layer` 记录并入前的新增层、原行位置和适用的 R2 保底；最终以 `expected` 为准。 |
| `by_stage.<学段>.new_p0_evidence` | 对集成基线同入口无 P0 的新增 P0，给出准入项、原文证据、一基行号与零基左闭右开列区间。同一原文可在多个入口或学段计数。 |
| `by_stage.<学段>.baseline_measured` | 每入口当前集成引擎的实测。命中三元组为规则、级别、一基原行号。事实表回填的未定位项用引擎原始行号 0。 |
| `by_stage.<学段>.expected_output`、`baseline_http_measured` | 评语及工具箱的最终契约和当前 HTTP 路由的实测。CLI 同时断言文本、JSON、私有编号不回显和合法数量对账。HTTP 报告保持合法编号、规则、级别、定位或静态建议。 |
| `by_stage.<学段>.baseline_changes` | 相对当前实测的变更集合，可含新增命中、去除误报、调整级别和修复输出；同一条可有多类改变。 |
| `filename`、`facts`、`payload`、`raw_body`、`private` | 原 CLI 文件名、事实表、HTTP 参数、原始异常请求和要检查的私有值。正常 HTTP `payload` 省略重复的字符串 `b`，用 `text` 还原；保留非字符串 `b` 变体。 `raw_body` 存在就直接发送该值。|
| `archive_only` | 写者冻结夹具里的摘录、输出片段等，保留其历史入口和匹配行为。 |

正文以三个学段分别记录，源探针会保留自己的学段。评语及工具箱测试按实际请求的学段，非法请求参数保留在 `payload`。原文中的 CR、CRLF 和 Unicode 换行以 JSON 字符转义保留。文件自身以 UTF-8、LF 编码。

## 实测基线

用一次性标准库脚本加载集成 `f17e6a31d687272292c9489097b65f0268eca8d0` 引擎，以及临时目录内 `eea12327e4533be39979b66dbc0f0d3630131563` 的脚本、共享姓名模块和词表。两版各执行 4,202 次入口检查，规则、级别、行号和输入错误均一致。当前集成另跑 48 个不同的本地 HTTP 请求。共用历史对照以规则、级别和行号为比较键，姓名表格行为及评语输出仍取当前集成实测。HTTP 实测与引擎直调列各自保留。
