# 清单投稿文案

## 一、提交时间和共同要求

**时间**：按《顶层设计》7.4 节，发布满 14 天（2026 年 11 月 14 日以后）或仓库满 100 star 后再提交 awesome 清单。skills.sh、SkillsMP 会自动收录，发布当天不必单独提交。

**现状（截至 2026 年 11 月 13 日）**：仓库已有 758 star（截至 2026-11-13），100 star 条件已满足，不必等到 11 月 14 日。各清单的实际投稿情况见第五章。

**门槛来源**：下文各清单的门槛，依据 2026 年 10 月 16 日读取的各仓库 CONTRIBUTING.md 和 README 整理。清单规则常有调整，提交前请再读一遍原文。

**共同要求**：

1. 一次只提交一个清单条目，不要同一天群发。
2. 描述写“它做什么”，不写广告语，不对读者喊话，不用 emoji。
3. 不出现关于 AI 检测、替人写稿、官方背书的说法。
4. 两个清单明确要求由本人提交：hesreallyhim/awesome-claude-code 要求推荐由真人在网页表单上填写；travisvn/awesome-claude-skills 不接受用 AI 生成或 AI 辅助提交的 PR。下面给这两个清单的文案只作要点参考，请用自己的话重写后手动提交。
5. 提交前确认：仓库已公开；根目录 LICENSE 的正文是 PolyForm Noncommercial 1.0.0，但 GitHub 目前识别为 Other，遇到要求许可证的清单，在提交说明里写明；如需让 GitHub 自动识别，需另行处理 LICENSE 文件；README 和 README_EN 首屏有定位、安装方法和保密提示；有 `examples/` 示例和评测报告。

## 二、通用简介

### 英文

dyz-gongwen-skills is an open-source collection of 22 Agent Skills for writing Chinese official documents (gongwen) in government agencies, public institutions and state-owned enterprises. Seventeen core skills cover task routing, drafting, revision, review and GB/T 9704 formatting; five industry packs serve township and community offices, public hospitals, universities, K-12 schools and SOEs. Facts are taken only from the user's materials, and missing data is left as a marked placeholder. The project includes a rule-based checker with clause references to GB/T 15834 and GB/T 15835, generates and repairs standard-compliant .docx files with python-docx, and pauses with a warning when the input carries classification or "internal use only" marks. Skills run in Claude Code, Codex, Cursor and other agents; prompt versions can be pasted into web or on-premise LLMs. Licensed under PolyForm Noncommercial 1.0.0: free for personal and noncommercial use.

### 中文

dyz-gongwen-skills 是面向机关、事业单位、国企文字工作者的开源公文写作 Skills 集合，共 22 个 skill：17 个核心 skill 覆盖任务路由、起草、改稿、核稿和 GB/T 9704 国标排版，5 个行业包面向乡镇社区、公立医院、高校、中小学和国有企业。事实只取自用户材料，缺的标【待补】，不编造；内置标注 GB/T 15834、GB/T 15835 条款号的机检规则，用 python-docx 生成和修复国标 docx；遇到密级或“内部资料”标识，先停下来提醒。支持 Claude Code、Codex、Cursor 等 Agent 工具，也提供可以粘贴到网页或内网大模型的提示词版。PolyForm Noncommercial 1.0.0 许可，个人及非商业用途免费。
