# 中小学引擎包分句判定方案（2026-11-25）

建议在共享姓名分支合入后，从集成分支另起引擎分支。复用 `gw_clause.py` 的分句坐标，在中小学包内建立“语境管辖哪个行为、谁对哪个对象做什么”的结构。基线结果独立保留，只有证据齐全的新增命中才升 P0。实现只用 Python 标准库。

## 二、分句与行为判定

### 内部数据

```text
Span       = 输入行号、起止列（左闭右开），表格另记表、行、列。跨行证据保存多个区间
Clause     = 句 ID、分句 ID、区间、前后分隔、父级框架、从属或并列关系
Frame      = 类型、提示词区间、已绑定的行为 ID、结束边界、证据是否明确
Action     = 分句 ID、谓词区间、类别、施事及角色、对象、接受方、项目 ID
             言语行为、正负极性、时间状态、强制证据、自愿证据、退出证据
             条件或指代指向、确定或待核、各字段的原文区间
Candidate  = 规则族、行为 ID、命中位置、级别、理由码、基线或新增
```

用 `dataclasses`、`enum`、`re` 与字符扫描。分句可含多个行动记录，嵌套行动可同时带“转述中的要求”等外层语境。正则只识别词、局部句法和角色模板。分句图和理由码留在内部，CLI 与 HTTP 不增加原文或诊断字段。

### 判定顺序

1. **定边界。** 按文种保留原段落、表格行与单元格坐标。顶层句号、问号、叹号和段落界定整句。逗号、分号、冒号切分句，分号仍允许同句宽层关联。顿号连接名词列表时共用同一谓词，连接带动作的项目时分别立项。“且、并、同时、还”后的独立谓词另记行为，排名规则按裁决视为分句界。显式新施事、转折或时序可结束原作用域。“并非、不仅”等先读作完整结构。Markdown 按未转义竖线切列，表头只作为列角色，不把另一数据行的项目或自愿带进本行。
2. **保留括注和引号。** 栈识别配对括号、引号、书名号与 `【待补】`。年级班号和名称内的标点保护为原子。带独立谓词的括注建立子分句，继承已确认的外层管辖，不能给旁边别的项目洗白。书名号或引号中的项目名、机构名保留为对象。带引述动词的完整引语建立转述框架，含规则用语的文件名只作出处候选。数字千位逗号、时间冒号及转义竖线不切分。配对失败、嵌套关系冲突时标记待核。
3. **先挂管辖，再定是否执行。** “严禁以下行为：”“如果发生如下情形：”“排查未发现：”打开框架，冒号后首项及同一列表中明确并列的同类项继承。仅允许显式引导语接紧邻的列表块，遇空行、同级标题、换主题或新独立声明即关闭。“收费通知：”是主题提示，后面的要求仍可成立。前置禁令可越过同一支配结构内的定语。后置“一律禁止、此方案已被否决、经核实并不属实、是否……”只回绑本句或显式列表中唯一指得上的内容。治理词后有独立执行行为，或正文明确陈述已实施后另作处置，分别判定两项。找不到唯一对象时给 P1。
4. **找施事、动作、对象。** 给每个谓词独立建记录。用紧邻主谓、`由/交由`、`把/将`、`向/给`、地点与受益人槽位区分施事、委托方、对象和接受方。“在家长群”是地点，“面向家长”是受众。省略施事仅从无换主语的显式并列，或文书内明确的本校发布主体继承。明确的校内通知祈使可作高置信，泛泛建议不补造施事。疑似动作跨逗号仍可整句共现兜底。
5. **绑定否定和言语行为。** 依次识别明确引述/疑问/条件/处置框架、分句内的极性，再判执行。状态含要求、肯定陈述实施、禁止或事实否定、假设或条件、转述或引用、疑问、治理或处置、待核。已生效的未来要求可算要求，“拟、建议研究、是否”须按支配关系判断。只在“否定词支配本谓词”时标负极性，允许夹介宾或把字结构。`不理想、不同、不断、不少于` 属所在定语、副词或数量，“未到岗”只修饰到岗，均不否定主行为。`绝非不/不得不/不是不` 与“不做（是）根本不行/绝对不可能/做不到”“不公布怎么行呢”在指向明确时按肯定或要求，保留句尾语气词。疑问“是否公布”及反问“难道可以公布吗”不能凭问号或固定反转判肯定。“不是不公布，而是暂缓”须按后项限定时间与事实。极性仍不清楚时不给新增 P0，也不抹掉基线。
6. **归并同项后出级别。** 项目键优先用明确对象，含字典外的“安全手册”等新宾语。仅唯一且有并列、复指、同一表行或邻近无竞争对象的关系才合并，支持先写自愿退出、后点项目。每项分别记“真实强制”“统一代办”“适用人群”“已报名后才缴费”。拒缴前件与制裁后件须同项相连。“严禁规定：未缴费者不发教材”整体是被禁的规定。“不报名不收费”是退出证据。冲突按第四节的门槛处理，基线与新增结果最后合并，保持既有输出顺序及同行同规则去重。被否定的候选只从这一条行为剔除，整句仍可保留其他共现证据。

## 三、共享模块与打包

- **直接用切分坐标。** `shared/scripts/gw_clause.py:34–74` 的 `split_clauses` 返回起止与后续分隔符，`split_sentences` 返回整句区间。中小学适配层先做等长标点投影，遮住受保护的标点，分别投影句界与分句界。共享版把分号视作整句分隔，K12 投影只在句界扫描中保护分号。对独立谓词或表格列补本地边界，再映射回原文。建议每块只扫描一次保护区间、各切分函数各调用一次，避免每个命中都重扫全文。现有函数的投影冒烟用禁令冒号、分号、书名号内冒号和千位逗号，核对 2 个句区间、5 个分句区间及原文坐标。这里只验证切分，不验证语义。
