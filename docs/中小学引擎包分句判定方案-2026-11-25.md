# 中小学引擎包分句判定方案（2026-11-25）

建议在共享姓名分支合入后，从集成分支另起引擎分支。由中小学包自带切分器，按文档构建“语境管辖哪个行为、谁对哪个对象做什么”的结构。基线结果独立保留，新增 P0 须通过封闭语境白名单和同分句证据门禁。实现只用 Python 标准库。

## 一、五轮失败的根因

| 根因与评审证据 | 评审原句 |
| --- | --- |

## 二、分句与行为判定

### 内部数据

```text
Span       = 原始行号、起止列（左闭右开）；表格增表、行、列
Clause     = 句 ID、分句 ID、区间、分隔和边界类型、上级 ID、并列关系
Frame      = 类型、提示区间、管辖区间、行为 ID 集、终止边界、前置白名单编号
Action     = 分句 ID、谓词、施事及角色、对象、接受方、项目 ID、时间与实施状态
             言语行为、正负极性、强制、自愿、退出、条件与指代边、证据区间、待核原因
Candidate  = 规则族、行为 ID、输出位置、级别、理由码、基线或新增
```

用 `dataclasses`、`enum`、`re` 和字符扫描。图在每份文档解析一次。结构字段与原文证据留在内部，CLI 与 HTTP 沿用现有字段和遮蔽约定。

### 判定顺序

1. **划边界。** 顶层句号、问号、叹号和段落界定整句，逗号、分号、冒号切分句。顿号的名词列共用谓词，独立动宾分别记行为。遇“并、且、同时、还”且右侧有独立谓词，建立新的分句和并列边。先保护“并非、不仅”等原子。跨行列表将引导语和紧邻编号或项目符号行连成一个块。空行、同级标题、缩进退出、表格边界或独立声明关闭块。每条命中仍定位最早的目标行为原行，证据可以分布多行。
2. **识别内外层。** 栈匹配圆括号、方括号、引号、书名号，保护千位逗号、时间冒号和 Markdown 转义竖线。书名、项目名、机构名留作词项。带独立谓词的括注、引文建立子分句，继承上层管辖，无谓词括注可作为插入语。残缺括号、未知引号用途或不明嵌套落待核。“严禁以下行为：”“如果发生如下情形：”“经排查未发现以下问题：”前导打开相应框，仅管冒号后紧邻内容和所属列表。明确标签才能开禁止、事实否定、假设、转述、疑问、治理框。例如“发现……的，一律取消评优资格”是处置条件，“对于……的行为，学校坚决零容忍”是治理。未列前缀保留为未知外层，结果至多 P1。
3. **抽取角色与执行状态。** 每个动作绑定谓词和必要槽位。紧邻主谓、`由/交由`、`把/将`、`向/给` 分别标责任施事、受事和接收方。地点“在家长群”和受众“面向家长”不充当施事。将“要求执行”“陈述实施中或已经实施”与“禁止/否定”“假设/条件”“转述/引用”“疑问”“治理/处置”分别记录。明确生效的未来要求可算要求。“拟、建议研究、考虑”标待核。称述他校、匿名举报、反面案例时保留来源和本校关系。施事省略限第一句封闭通知式或白名单内的显式并列传递，无法唯一落实角色给 P1。
4. **绑定否定。** 每次只更新被支配的谓词或动作边，按下列四步执行。回绑表在输出级别前运行。
5. **按收费项目合并。** 优先用明确对象建项目键，字典外如“安全手册”也能成为对象。仅有唯一的同项复指、并列或表格列关系才合并，区分真实强制、统一代办、适用人群、已报名后的缴费。拒缴与后果必须同项，跨分句才拼齐时首版至多 P1。同一 Markdown 行出现不同项目，按项目列开始到下一项目列前分段。表头指定列角色，无表头时从明确项目名起段，无法分段时标待核。退出证据只留在本段，跨数据行也不可借用。随后按第四节出级别，同行同规则按既有方式去重。

### 否定四步

1. **最长词元优先。** 先扫描明确复合结构，再扫描较短词元。一次消费“不断、不同、不理想、不达标、不少于、不超过、不低于、不管、不论、不便、不足、不仅、不但、不只、不光、不止、不单、不一、不等、不均、不定期、不定时”。这些词可以描述性质、数量、让步、频次或原因，不产生对主动作的负极性。必须有可消费的后续槽位，例如“不管＋家长意见”后接“一律”；不能唯一切词时标待核。其余再找“并非不/不是不/不得不”等组合和“严禁、禁止、不得、不准、切勿、不可”“不、未、没有、免收”等词元。
2. **圈定语岛。** 在同一分句内找最近非并列的“成分＋的＋学生/新生/同学/家长/家庭/班级/人员”。岛内否定结束于中心名词，岛外否定扫描把全岛视为一个名词槽。“未报名的学生”中的“未”只绑定报名，外层“不得要求”越岛继续管缴费。无法区分两个定语边界则不出新增 P0，也不凭猜测回写基线豁免。
3. **追到第一个实义谓词。** 否定与目标之间只允许规则列明的插入项。介宾/处置槽限“在/于/向/对/给/将/把＋已识别地点、对象或受事”，时点限“本/下周、周一至周日、周末、寒暑假、开学前、日期、在/于＋时点＋前/后”，方式频度限“私下、变相、再次、强行、随意、一律、统一”。无独立谓词括注可跨，例如“（以任何名义）”。先遇“到岗、报名、分班、购买、免收、取消减免”等另一实义动作，就先将局部否定绑定该动作。后遇“由、各班、学校、后、并、且”关闭该局部边；“因＋明确原因＋新施事”另建原因边。无法消费的插入项标待核。
4. **判并列、双重否定与反问。** 局部“不/未/没有/免收”到“并/且”结束；外层“严禁/禁止/不得/不准/切勿/不可”跨“并、且、顿号、和”管同属的动宾链。句末、显式转折、新主体加明确执行词或列表结束关闭外层；禁令切出的后项首版至多 P1。`绝非不 V`、`并非不 V`、`不得不 V` 恢复对 V 的肯定；`并非不可行/并非不能`只确认可行/可能。唯一动作的“不 V 是绝对不可能的/根本不行/做不到”“不 V 怎么行呢”恢复要求。普通“是否 V”给 P1，“难道可以 V 吗”不按肯定反转。“不是不 V，而是……”的后项若明确给出执行时间或方式并重复 V，恢复执行语义；对象需从前项补齐则 P1。后项明确“暂缓、待定、另行通知”给 P1；明确“不公布”或同项“自愿且可退出”等合规替代且未实际执行，跳过新增；后项无法确定给 P1。

### 后置回绑三分表

只在同句或显式列表内绑定唯一候选。无回指词时须紧邻且无竞争动作；显式“此方案/该做法/这是”必须唯一对上。指代不唯一、另有独立实际执行、姿态词未识别时，只能给自身证据可支持的级别；受待核外层牵连的候选给 P1。

| 末段类别 | 识别证据和首版判定 |
| --- | --- |
| 禁令或辟谣 | “一律禁止/坚决反对/坚决零容忍”直接评前项，或“经核实并不属实/查无实据”否定前项事实。绑定确定则跳过新增。 |
| 事后问责或处置 | “已启动问责/已遭处分/已立案查处”或明确已实施以后才叫停。绑定行为的新增层固定 P1。 |
| 提问、否决或叫停 | “是否……？”给 P1。仅有提议且“已被否决/未予采纳”，或“这是往年被督导叫停的错误做法”这类明确历史引述且当前未执行，跳过新增。实施状态不明给 P1。最终按 K1/R2 合并；有 `parents` 未豁免基线则 `general` 保底 P1。 |

### 新增 P0 的封闭入口

**新增 P0 的全部角色、必要对象、极性和执行证据必须在同一分句。非句首分句必须有白名单前置才可能升 P0，未知外层语境一律 P1。** 这是规则实现的硬约束。所有新增升级路径只能调用同一门禁，图中须记录正向准入项及原文区间。切出禁令、跨分句回指、从上句补动作或对象、状态无法识别的候选，即使能确认核心共现也至多 P1。前置禁令跨并列的明确受辖项、后置回绑明确跳过项仍按各自的结构处理。

| 准入项 | 必备证据 |
| --- | --- |
| 句首主句 | 从句首到行为末尾须消费为完整的肯定动作结构。并列共用主语时只按下表的独立并列项绑定。允许显式主体、第二节封闭时点与方式槽（含地点状语“在家长群”、频次“不断”）、定语岛、`由/把/向` 槽和“现/请/须/应/必须/一律/统一/即日起”等执行信号；明确行为陈述可无模态词。第一个未消费词段、引述口或不明上下级即标待核。仅规则声明的固定反问、双重否定和直接身份陈述可恢复相应肯定。 |
| 肯定通知头 | 冒号前完整匹配“收费通知/关于课后服务收费的通知/现通知如下/经研究决定”。冒号后只给紧邻、未加新外层的第一项资格，后项仍须独立证明。 |
| 独立并列 | 匹配显式 “但/另/并” 前置。首版只收两个完整结构：“某项目自愿＋明确退出，但＋独立新主体和新项目”；“学校免收/不统一订购＋明确项目，并＋同主体的新执行动作和明确新项目”。完整前项须由结构正向识别。紧邻并列可共享同一主语槽，不能借前项证明缴购对象、强制或有偿。“另”只在另有明确主体和项目时适用。带上层禁令的前项不进入本项。 |

任何白名单扩充都须列出新结构、负例和留出样例结果。括注、引文或未知引导后的独立候选首版没有单独升档通道。标题和引导语只证明语境，仍需动作证据齐全。对句首看似完整、逗号后却有未解析附加评价的句子，只有能证明后段与候选无关才可维持 P0。后段语境未知且可能回指时给 P1。

### 真实失败句走查

义务教育示例。以下为**手推预期**，`P/G` 表示 `parents/general`，只列对应规则族；“跳过”仍须跑 K1/R2。★ 为旧窄模板的八条对照。评审第四节标出的缺口和边界均列出。

| 来源与原句 | 绑定过程与结果 |
| --- | --- |
| 评审 #1，R5 `NT_01` “严禁以下行为：班主任组织学生参加校外有偿补课。” | 禁令冒号和可能的续行同框。P/G 均跳过补课。 |
| 评审 #2／#3，R5 `NT_06/13` “严禁作出如下规定：未缴纳校服费者不发教材。”“经排查未发现以下问题：学校统一订购教辅资料。” | 禁令管辖拒缴和后果，排查否定管辖订购。两句 P/G 均跳过收费强制。 |
| 评审 B1 补例 “校务会驳回了以下提议：学校统一订购教辅资料。”“以下为反面典型案例：全体学生必须购买校服。” | 未列入通知头白名单，不能把内容当本校执行。“驳回了以下提议”完整匹配明确否决框时跳过新增，既有基线照合并；未知案例引导且有核心动作给 P/G P1。 |
| 评审 #4／#5 “关于课后服务收费的通知：全体学生周三前交齐150元。”“发现教师组织学生参加校外有偿补课的，一律取消评优资格。” | 前句通知头明确项目语境，但“全体”在此只表人群且金额未在分句内绑定具体项目，P/G 均收费 P1。后句是处置条件，P/G 均跳过补课。 |
| 评审 #7 “如果发生如下情形：教师向校外培训机构提供家长电话，学校将坚决制止。” | 条件框管辖提供信息，后段声明制止，P/G 均跳过。 |
| 评审 B1 外校补例 “某外校曾发生班主任组织学生参加校外有偿补课的问题，我校要引以为戒。” | 他校既往事件加本校警示，无本校执行断言。明确绑定时两入口跳过新增；未知警示语境则 P1。 |
| 评审 #6，R4 `NEG_13` “对于班主任向校外培训机构提供学生信息的行为，学校坚决零容忍。” | 前项挂“对于…的行为”，后项明确禁令回绑唯一行为。P/G 均跳过。 |
| 评审 #8，R4 `NEG_01` “严禁要求经济困难的学生统一购买校服。” | “学生”闭定语岛，严禁经“要求”跨岛管购买。P/G 均跳过。 |
| 评审 #9，R4 `NEG_02` “不得要求未报名的学生必须缴纳课后服务费。” | 岛内“未”只管报名；外层“不得要求”跨岛管缴纳。P/G 均跳过。 |
| 评审 #10，R5 `NT_08` “教师将学生名单提供给校外培训机构，一律禁止。” | 后置禁止回绑唯一“提供”。P/G 均跳过。 |
| 评审 #11，R5 `NT_10` “学校统一办理意外伤害保险，此方案在教代会上已被否决。” | 回绑否决，跳过新增精确层。P 留 `JZ-006 P0`，G 保底 `K12-G05 P1`。 |
| 评审 #12／B1 辟谣补例 “网传谣言称，班主任把学生电话发给校外培训机构，经核实并不属实。”“针对‘班主任把学生电话发给校外培训机构’的匿名举报，经核查查无实据。” | 引述来源与唯一被否定前项相连。P/G 均跳过。 |
| 评审 #13，R5 `NT_14` “班主任向校外培训机构输送生源，是否属于师德红线？” | 提问回绑唯一前项，发生状态待核。P/G 均 P1。 |
