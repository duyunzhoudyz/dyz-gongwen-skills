# 过程记录：D　中小学评语本地脱敏、批量生成、机检与还原

> 演示行业包 `gongwen-k12` 的隐私保护闭环：真实学生姓名全程不进模型对话，只在本机完成脱敏与还原。所有姓名与事实均为虚构。

## 第一步　本机脱敏（学生姓名不交给 AI）

```bash
python skills/gongwen-k12/scripts/k12_check.py mask 输入-五年级二班学生事实表.csv --drop-sensitive
```

脚本实际产出 `输入-五年级二班学生事实表-脱敏.md` 与 `输入-五年级二班学生事实表-对照表.csv`；本目录的示例文件是重命名后的：
- `1-本机脱敏事实表.md`（姓名替换为 `S01`～`S04`，仅把这一份交给模型）；
- `对照表-仅本机留存示意.csv`（真实场景只留在本机，切勿发给模型）。

## 第二步　按脱敏事实表生成编号版评语

调用 `gongwen-k12` 评语专项：每生至少两件具体表现 + 一条可执行建议、第二人称、开头轮换、句句回查事实表，产出 `2-模型生成评语-编号版.txt`。

## 第三步　评语批量机检与事实表对账

```bash
python skills/gongwen-k12/scripts/k12_check.py comments 2-模型生成评语-编号版.txt --facts 1-本机脱敏事实表.md --strict
```

结果见 `3-评语机检报告.txt`：**P0 0 条、P1 0 条、P2 0 条**，无雷同、无排名分数、无标签化贬损、无家庭隐私外露。

## 第四步　本机还原姓名版

```bash
python skills/gongwen-k12/scripts/k12_check.py unmask 2-模型生成评语-编号版.txt 对照表-仅本机留存示意.csv
```

产出 `4-本机还原姓名版.txt`（4 处编号全部还原），姓名版只在本机打印或导入教务系统，不再发回 AI。
