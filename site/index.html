一、和普通 AI 写材料有什么不同

公文写作最怕编造、泄密和格式出错。这套 skill 把这几件事写成规则，并尽量用脚本检查，而不是靠模型自觉。

比较项一般的 AI 写作dyz-gongwen-skills
数据和案例缺了就编只用你给的材料，缺的标【待补】
篇幅越写越长，素材不够就注水你定了字数就按字数写，不新增事实、不注水
文风AI 腔、新八股去掉 AI 腔，保留“一是二是”、排比小标题这些公文正当写法
态度对冲、免责声明措辞明确，需要核实的事项放到正文之外
格式自己排安装版一键生成 GB/T 9704 国标 docx，机检标点、数字、发文字号；网页版提供手动设置清单
单位差异一刀切7 类单位画像、5 种角色模式、5 个行业包

所有 skill 都遵守的六条写作红线

这六条的优先级高于任何具体流程。规则依据《党政机关公文处理工作条例》、GB/T 9704-2012、GB/T 15834-2011、GB/T 15835-2011 和《整治形式主义为基层减负若干规定》，每条规则标注条款号。

  • 保密先于生成

    发现密级标识、“内部资料”“工作秘密”字样或个人敏感信息，先停下来提醒。

  • 事实只来自用户

    数据、案例、文号、政策依据都只取自你的材料；必须由你补的标【待补】，存疑的列在起草说明里。

  • 正文干净，提示外置

    正文里没有免责声明和 AI 自述，需要核实的放到“起草说明”。

  • 默认做减法

    开门见山，遵守减负规定的篇幅要求，不照抄上级文件；你指定字数就按字数写，不新增事实、不注水。

  • 规则可溯源、可机检

    每条格式、标点、数字规则都标注条款号，能用脚本检查的就不靠模型自觉。

  • 辅助不代笔

    对照检查、述职等需要本人经历的材料，没有素材就只给提纲。

机检引擎按这些规则做 12 类检查，覆盖 41 类文书。全文见仓库中的 shared/guardrails.md。

三、22 个 skill 一览

17 个核心 skill 装在一个插件里，5 个行业包按需选装。不用记 skill 名，直接说需求，总入口会判断文种并转交。

入口与配置2 个 skill

先接住需求，再建好单位画像。

  • 总入口gongwen

    接住说不清的需求，判断文书类型和行文方向，3 个问题建简版单位画像，规划路线。

  • 单位画像gongwen-profile

    完整建档；学本单位历史稿文风；归纳领导改稿偏好；管理禁用词。

起草8 个 skill

从法定公文到讲话、纪要、整改材料，先定文种再成稿。

  • 法定公文gongwen-draft

    通知、请示、报告、函、通报、批复、意见、签报、决定、通告、公告；先定文种再成稿。

  • 综合文稿gongwen-report

    总结、计划、工作要点、汇报、调研报告、经验材料、述职述责述廉、实施方案、大会报告。

  • 讲话类gongwen-speech

    领导讲话、主持词、致辞、表态、交流和代表发言；按时长定字数，写成口语稿。

  • 党建与组织生活gongwen-party

    对照检查、党建报告、党课、研讨发言、心得汇报、“三会一课”记录整理；无本人事例只给提纲。

  • 信息简报gongwen-brief

    政务信息、简报、新闻稿、公众号推文；长材料压成信息；评估能否被采用。

  • 会议纪要gongwen-minutes

    会议记录、纪要、上会议题材料、督办清单；只整理不添加，分清同意、原则同意和暂缓。

  • 上级文件转化gongwen-implement

    提取要点、任务分解表、实施方案、落实情况报告；检测照抄原文，提示层层加码。

  • 整改材料gongwen-rectify

    整改方案、台账（可转 Excel）、整改进展报告、自查报告；报告与台账逐条对账。

改稿质检5 个 skill

标题、润色、去 AI 味、去防御性、核稿。

  • 标题与提纲gongwen-title

    公文标题、主副标题、三套小标题方案、提纲，检查标题与正文是否对应。

  • 改稿润色gongwen-polish

    压缩、扩写、语气互转、大白话转公文、按领导批注改、多稿合并。

  • 去 AI 味gongwen-humanize

    改掉 AI 腔，保留公文正当写法，以保住事实为前提，评测中事实保持率 99.6%。

  • 去防御性gongwen-direct

    删免责声明，把“建议”“可以考虑”改成要求，让请示有倾向性意见。

  • 核稿审校gongwen-review

    按“八关”核稿，出分级问题清单；机检标点、数字、格式、保密隐私、禁用词。

交付工具2 个 skill

排成国标 Word，整理数据与图表。

  • 国标排版gongwen-format

    按 GB/T 9704-2012 生成红头、信函、纪要、白头、材料、简报六种版式 Word；修复已有 docx。

  • 数据与图表gongwen-data

    报表体检、同比环比计算（附算式）、数据写成公文句子、本机生成黑白灰 Excel 图表。

行业包5 个 skill，单独安装

装在核心 skill 之上，按单位类型选装。

  • 乡镇街道社区gongwen-grassroots

    迎检汇报、居民通知、应急通知、工作台账、村居务公开。

  • 公立医院gongwen-hospital

    等级评审自评、绩效分析、RCA/PDCA、科室述职（DRG/CMI）、党委会和院长办公会议题。

  • 高校gongwen-university

    审核评估自评、学科评估、申报书审查、学院总结、签报和两级发文判断。

  • 中小学gongwen-k12

    学期计划总结、督导评估自评、家长会讲话、学生评语、致家长一封信。

  • 国有企业gongwen-soe

    “三重一大”议题、董事会议案、总经理办公会纪要、ESG 报告、合规管理报告。

四、安装与快速开始

先看你在用什么工具，选对应的方式。每条命令都可以一键复制。

Claude Code：插件市场

/plugin marketplace add duyunzhoudyz/dyz-gongwen-skills
/plugin install gongwen@dyz-gongwen-skills

两行命令装好 17 个核心 skill。行业包按需选装，以医院为例：

/plugin install gongwen-hospital@dyz-gongwen-skills

Codex、Cursor、Gemini CLI、GitHub Copilot 等：npx skills

npx skills add duyunzhoudyz/dyz-gongwen-skills

需要先装 Node.js。

一键安装脚本（Windows、macOS、Linux）

先下载仓库。会用 git 的运行下面第一条命令；不会的，在仓库页点绿色 Code 按钮，选 Download ZIP，下载后解压。然后在仓库文件夹里运行脚本。

下载仓库 
git clone https://github.com/duyunzhoudyz/dyz-gongwen-skills.git
Windows（PowerShell） 
powershell -ExecutionPolicy Bypass -File .\install.ps1
macOS、Linux 
bash install.sh

脚本检查 Python（3.9+），询问是否安装排版依赖，然后把 17 个核心 skill 装进本机找到的全部 Agent 工具。只想看会装到哪里而不写入文件：Windows 末尾加 -WhatIf，macOS、Linux 加 --dry-run。选装行业包：bash install.sh --pack hospital，可多选，--pack all 装全部。

DeepSeek、豆包、Kimi 等网页版，或单位内网模型：不用安装

打开仓库里的 dist/prompts/，复制提示词文件全文，粘贴到对话开头，再说出你的需求。第一次用，从 gongwen.md（总入口）开始。

每个 skill 对应一份提示词，每份不超过 2.9 万字符。需要换到下一个 skill 时，当前对话会给你一张交接卡：新开对话，先粘贴下一份提示词，再粘贴交接卡和材料。单位内网使用，可生成离线包（输出到 dist/offline/）：

python tools/build_prompts.py --offline

已经在用 Agent，不想敲命令：让 Agent 自己装

把这段话发给你的 Agent：

请把 https://github.com/duyunzhoudyz/dyz-gongwen-skills 中 skills/ 目录下的 skill 安装到你的 skills 目录。
其中 gongwen-grassroots、gongwen-hospital、gongwen-university、gongwen-k12、gongwen-soe 是行业包，
只装我需要的 gongwen-hospital。装好后告诉我有哪些可用。

排版和 Excel 图表需要 Python 3.9+ 及 python-docx、openpyxl。没有 Python 时，排版 skill 给出 WPS/Word 手动设置清单。

pip install python-docx openpyxl

常见问题

这个项目是什么，收费吗？

dyz-gongwen-skills 是给机关事业单位、国企文字工作者用的公文写作 Skills 集合，共 22 个 skill。按 PolyForm Noncommercial 1.0.0 许可证源码公开（source-available，不是 OSI 意义上的开源），个人及非商业用途免费；商业用途请联系作者。

没有 Claude，能用吗？

能。Skill 版支持 Claude Code、Codex、Cursor、Gemini CLI、GitHub Copilot、Qwen Code、Kimi Code CLI 等工具。没有这些工具的，用提示词版：打开仓库的 dist/prompts/，复制文件内容粘贴到 DeepSeek、豆包、Kimi 等网页大模型，或单位内网部署的模型。

单位的材料能直接贴进去吗？

涉密材料和标注“内部资料”“工作秘密”的材料，不能输入任何联网 AI 工具。处理内部材料请用单位内网部署的模型；提示词版和离线包可以在内网使用。skill 发现密级标识时会先停下来提醒，但判断责任在使用者。

它会不会编数据？

规则要求只用你给的材料，必须由你补的标【待补】，存疑的列在起草说明。v1.0 评测中，修复后第二轮重测的 136 条故意少给材料的用例，装 skill 编造 0 次（第一轮 134 条中有 8 次）。模型输出有随机性，定稿前请逐条核对数字、人名、文号。

去 AI 味能让稿子查不出是 AI 写的吗？

不能，也不承诺这种效果。去 AI 味改的是文风质量，目的是让稿子更好读。

排出来的 Word 字体不对，或者没有 Python，怎么办？

项目不随附字体，也不会用别的字体顶替。缺字体时，排版 skill 会在回复开头指出缺哪几款，并告诉你怎么安装；装好后重启 Word/WPS 再核对。没有 Python 时，排版 skill 给出 WPS/Word 手动设置清单。
